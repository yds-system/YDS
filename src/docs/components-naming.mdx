export const CompRow = ({ comp, elementFilter, modifierFilter }) => {
  const allEls = comp.elements.filter(e => e.class !== comp.baseClass);
  const els = elementFilter ? allEls.filter(elementFilter) : allEls;
  const mods = modifierFilter ? comp.modifiers.filter(modifierFilter) : comp.modifiers;
  return (
    <tr>
      <td>{comp.name}</td>
      <td>{comp.englishName}</td>
      <td><code>{comp.baseClass}</code></td>
      <td>{els.map((e, i) => <span key={i}><code>{e.class}</code>{' '}</span>)}</td>
      <td>{mods.map((m, i) => <span key={i}><code>{m.class}</code>{' '}</span>)}</td>
      <td>{comp.description}</td>
    </tr>
  );
};

# 컴포넌트 네이밍 정의서

범정부 UI/UX 디자인 시스템(KRDS) 기반 ds- BEM 규칙 클래스명 정의서입니다.
KRDS 원본 클래스는 각 항목의 'KRDS 원본' 열을 참고하세요.

---

## 기반 (Foundation)

디자인 시스템의 기초 요소. 색상·타이포그래피·간격·아이콘 등 모든 컴포넌트가 공유하는 리소스입니다.

| 항목 | Storybook 경로 | 설명 |
|---|---|---|
| 아이콘 | `기반/아이콘` | CSS `mask-image` 기반 SVG 아이콘 (~65종). `ds-icon` + `ds-ico-*` 클래스 |
| 색상 토큰 | `기반/색상` (예정) | KRDS 색상 토큰 (`--krds-light-color-*`) |
| 타이포그래피 | `기반/타이포그래피` (예정) | 서체·크기·행간 토큰 |
| 간격 | `기반/간격` (예정) | 여백·패딩 토큰 (`--krds-spacing-*`) |

## 패턴 (Pattern)

여러 컴포넌트를 조합한 페이지 레벨 구조. KRDS에 정의된 조합 규칙을 따릅니다.

| 컴포넌트명(한글) | 영문명 | 구성 요소 | 설명 |
|---|---|---|---|
| 기본 레이아웃 | Basic Layout | 헤더(`ds-header`) + GNB(`ds-main-menu`) + 푸터(`ds-footer`) | 서비스 기본 페이지 레이아웃 조합 |

## 추후 추가 예정

아직 Storybook에 구현되지 않은 KRDS 컴포넌트 목록입니다.

| 컴포넌트명(한글) | 영문명 | 기본 클래스명 |
|---|---|---|
| 마스트헤드 | Masthead | `krds-masthead` |
| 사이드 네비게이션 | Side Navigation | `krds-side-navigation` |
| 페이지 내 네비게이션 | In-Page Navigation | `krds-in-page-navigation-type` |
| 건너뛰기 링크 | Skip Link | `ds-skip-link` |
| 식별자 | Identifier | `krds-identifier` |
| TTS | TTS | `krds-tts` |
| 언어 전환 | Language Switcher | `krds-drop-wrap` |
| 화면 크기 조절 | Resize | `krds-drop-wrap` |
| 토글 스위치 | Toggle Switch | `krds-form-toggle-switch` |
| 모달 | Modal | `krds-modal` |
| 로딩 스피너 | Spinner | `form-spinner` |
| 중요 공지 | Critical Alerts | `krds-critical-alerts` |
| 코치 마크 | Coach Mark | `krds-coach-mark` |
| 맥락적 도움말 | Contextual Help | `krds-contextual-help` |
| 공개/비공개 | Disclosure | `krds-disclosure` |
| 구조화된 목록 | Structured List | `krds-structured-list-type-full` |
| 텍스트 목록 | Text List | `krds-info-list` |
| 단계 표시 | Step Indicator | `krds-step-wrap` |
| 도움말 패널 | Help Panel | `krds-help-panel` |
| 튜토리얼 패널 | Tutorial Panel | `krds-help-panel` |
