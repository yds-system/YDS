# Mode

모드 토큰

<PageTocMode />

> `mode.css`에서 정의. `html` 요소의 `data-mode` 속성 하나로 모드가 전환됩니다.
>
> 색상 토큰은 반드시 프리미티브를 `var()`로 참조하며, hex 직접 사용은 금지입니다.

<ModeInfoBox />

## 색상

라이트(기본) · 다크(`[data-mode="dark"]`)의 참조·값을 함께 표시합니다.

표의 `L · D` 열 색상 견본은 왼쪽부터 라이트 / 다크 순입니다.

<ColorSemanticTable />

## 그림자색

그림자 색상 토큰입니다. 현재 모든 모드에서 동일하며 `mode.css`에 정의됩니다.

`semantic.css`의 `--shadow-s / --shadow-m / --shadow-l` 토큰이 이 값을 참조합니다.
