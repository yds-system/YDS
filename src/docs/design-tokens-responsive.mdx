# Responsive

반응형 토큰

<PageTocResponsive />

> `responsive.scss`에서 정의. PC 기본값을 `:root`에 두고, `@media (max-width: 1279px)` 블록으로 모바일 값을 덮어씁니다.
>
> **원칙 (KRDS 기준)**: 같은 종류는 한 컬렉션에 — 글자 크기·행간은 PC/모바일 값이 같아도 responsive에 정의합니다.
> PC = 모바일인 토큰은 `@media` 블록에 중복 작성하지 않습니다.

---

## 타이포그래피

Display(신규)·Heading·내비게이션 제목 중 PC/모바일에서 크기가 달라지는 토큰입니다.

`heading-s`, `body-*` 등 PC = 모바일인 font-size 토큰도 responsive에 정의되어 있지만, 값이 고정이므로 아래 표에는 포함하지 않습니다.

## 간격 그룹

space alias 토큰 xs~xl 전체입니다. xs·s 그룹은 PC = 모바일(고정값), m·l·xl 그룹은 모바일에서 한 단계 작은 값으로 전환됩니다.
