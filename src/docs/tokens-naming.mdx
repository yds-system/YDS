# 디자인 토큰 네이밍 제안서

> **상태: 초안** — 코드에 아직 적용되지 않았습니다. 현재는 `--krds-*` 토큰을 직접 참조합니다.  
> 실제 적용 시 `src/tokens/` 폴더에 생성하고 컴포넌트 CSS를 일괄 교체합니다.

---

## 네이밍 규칙

### 형식

```
--{분류}-{대상}-{역할}-{상태}
```

- **접두사 없음** — `--ds-`, `--krds-` 등 접두사를 붙이지 않는다.  
  컴포넌트 내부 변수(`--ds-btn--color-*`)와 구별하기 위함.
- **이름만 보고 용도를 알 수 있게** 짓는다. `--primary`, `--text` 같은 한 단어 이름은 금지.
- 상태 세그먼트는 **필요한 것만** 붙인다.

## 프로젝트 테마 예시

`data-theme` 속성으로 프로젝트별 브랜드 컬러를 덮어씁니다.  
Primary 계열만 교체하면 버튼·링크·포커스 등 UI 전체가 일관되게 바뀝니다.

```css
/* src/tokens/theme-project-a.css */

[data-theme="project-a"] {
  /* Primary 배경 계열 */
  --color-bg-primary:       #5c2d91;   /* 보라 계열 브랜드 */
  --color-bg-primary-hover: #4a2370;

  /* Primary 텍스트 */
  --color-text-primary:     #5c2d91;

  /* Primary 테두리 (포커스 링 포함) */
  --color-border-focus:     #5c2d91;
}
```

```html
<!-- 페이지 루트에 theme 속성 부여 -->
<html lang="ko" data-theme="project-a">
```

## 컴포넌트 CSS 마이그레이션 예시

현재 컴포넌트 CSS는 `--krds-*` 토큰을 직접 참조합니다.  
토큰 작업 시 아래와 같이 교체합니다.

### 예시 1 — 버튼 Primary 배경

```css
/* 현재 (button.css) */
--ds-btn--color-primary-fill: var(--krds-light-color-button-primary-fill);

/* 변경 후 */
--ds-btn--color-primary-fill: var(--color-bg-primary);
```

### 예시 2 — 버튼 기본 텍스트

```css
/* 현재 (button.css) */
--ds-btn--color-tertiary-text: var(--krds-light-color-text-basic);

/* 변경 후 */
--ds-btn--color-tertiary-text: var(--color-text-default);
```

### 예시 3 — 입력 필드 테두리

```css
/* 현재 (button.css 내 border 예시) */
border: 0.1rem solid var(--krds-light-color-border-gray);

/* 변경 후 */
border: 0.1rem solid var(--color-border-default);
```

> 교체 범위: `src/components/**/*.css` 전체.  
> `reference/krds/`는 수정하지 않는다.

## 적용 절차 (추후)

1. `src/tokens/base.css` 생성 — `:root` 에 위 토큰 정의
2. `src/tokens/theme-*.css` 생성 — 프로젝트별 `[data-theme]` 오버라이드
3. `preview.js` import 순서: `base.css` → `theme-*.css` → `component.css`
4. 컴포넌트 CSS에서 `--krds-light-color-*` / `--krds-number-*` 등을 새 토큰으로 교체
5. `CLAUDE.md` 토큰 섹션 업데이트
