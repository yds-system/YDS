# 디자인 토큰 네이밍 제안서

> **상태: 초안** — 코드에 아직 적용되지 않았습니다. 현재는 `--krds-*` 토큰을 직접 참조합니다.  
> 실제 적용 시 `src/tokens/` 폴더에 생성하고 컴포넌트 CSS를 일괄 교체합니다.

---

## 필수 전제 — `html { font-size: 62.5% }`

이 시스템의 모든 rem 값은 **1rem = 10px** 기준으로 설계됩니다.

```css
/* src/global/reset.css 또는 base.css */
html {
  font-size: 62.5%; /* 16px × 62.5% = 10px */
}
```

> 이 설정이 없으면 `1.6rem`이 16px가 아닌 25.6px(기본 16px 기준)로 렌더링됩니다.  
> KRDS도 동일한 전제를 사용합니다 (`reference/krds/resources/css/common/common.css` 참고).

## 네이밍 규칙

### 형식

```
--{분류}-{대상}-{역할}-{상태}
```

- **접두사 없음** — `--ds-`, `--krds-` 등 접두사를 붙이지 않는다.  
  컴포넌트 내부 변수(`--ds-btn--color-*`)와 구별하기 위함.
- **이름만 보고 용도를 알 수 있게** 짓는다. `--primary`, `--text` 같은 한 단어 이름은 금지.
- 크기 표기는 **풀네임**으로 통일한다: `small` / `medium` / `large` (축약형 `sm`, `md` 금지).
- 상태 세그먼트는 **필요한 것만** 붙인다.

**미디어 쿼리 덮어쓰기 예시** (`--font-size-heading-medium` PC 2.4rem → 모바일 2.2rem):

```css
/* src/tokens/base.css */
:root {
  --font-size-heading-medium: 2.4rem;   /* PC: --krds-pc-font-size-heading-medium */
}

@media (max-width: 1279px) {
  :root {
    --font-size-heading-medium: 2.2rem; /* 모바일: --krds-mobile-font-size-heading-medium */
  }
}
```

컴포넌트 CSS는 `var(--font-size-heading-medium)` 하나만 참조하면 뷰포트에 맞게 자동 전환됩니다.

## 테마 · 다크 모드 원칙

### 프로젝트 테마

`data-theme` 속성으로 프로젝트별 브랜드 컬러를 덮어씁니다.  
Primary 계열만 교체하면 버튼·링크·포커스 등 UI 전체가 일관되게 바뀝니다.

```css
/* src/tokens/theme-project-a.css */

[data-theme="project-a"] {
  /* Primary 배경 계열 */
  --color-bg-primary:       #5c2d91;   /* 보라 계열 브랜드 */
  --color-bg-primary-hover: #4a2370;

  /* Primary 텍스트 */
  --color-text-primary:     #5c2d91;

  /* Primary 테두리 (포커스 링 포함) */
  --color-border-focus:     #5c2d91;
}
```

```html
<!-- 페이지 루트에 theme 속성 부여 -->
<html lang="ko" data-theme="project-a">
```

### 다크 모드

필요 시 `[data-mode="dark"]`에서 같은 이름의 `color` 토큰을 덮어씁니다.  
토큰 이름이 역할 기반이므로 컴포넌트 CSS는 건드리지 않아도 됩니다.

```css
/* src/tokens/mode-dark.css */

[data-mode="dark"] {
  --color-bg-default:    #1e2124;
  --color-bg-subtle:     #33363d;
  --color-text-default:  #f4f5f6;
  --color-text-subtle:   #b1b8be;
  /* … */
}
```

## 컴포넌트 CSS 마이그레이션 예시

현재 컴포넌트 CSS는 `--krds-*` 토큰을 직접 참조합니다.  
토큰 작업 시 아래와 같이 교체합니다.

### 예시 1 — 버튼 Primary 배경

```css
/* 현재 (button.css) */
--ds-btn--color-primary-fill: var(--krds-light-color-button-primary-fill);

/* 변경 후 */
--ds-btn--color-primary-fill: var(--color-bg-primary);
```

### 예시 2 — 버튼 기본 텍스트

```css
/* 현재 (button.css) */
--ds-btn--color-tertiary-text: var(--krds-light-color-text-basic);

/* 변경 후 */
--ds-btn--color-tertiary-text: var(--color-text-default);
```

### 예시 3 — 입력 필드 (text-input.css)

```css
/* 현재 (text-input.css) */
--ds-input--color-text-placeholder: var(--krds-light-color-text-disabled);
--ds-input--color-border-active:    var(--krds-light-color-input-border-active);
--ds-input--color-border-error:     var(--krds-light-color-input-border-error);

/* 변경 후 */
--ds-input--color-text-placeholder: var(--color-text-disabled);
--ds-input--color-border-active:    var(--color-border-focus);
--ds-input--color-border-error:     var(--color-border-danger);
```

> 교체 범위: `src/components/**/*.css` 전체.  
> `reference/krds/`는 수정하지 않는다.
