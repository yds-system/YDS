# 시멘틱 토큰

<PageTocSemantic />

> `semantic.css`에서 정의. 용도 기반으로 프리미티브를 `var()`로 참조합니다.

> 모드별 색상은 **모드** 페이지, 반응형 타이포·간격은 **반응형** 페이지에서 확인하세요.

---

## 고정 색상

모드와 무관하게 항상 같은 값을 유지하는 색상 토큰입니다.

`mode.css`의 `--color-text-on-primary / --color-text-on-secondary`(모드별 가변)와 달리, 이 토큰은 어두운 채움(dark fill) 배경 위에서 항상 흰색으로 표시됩니다.

<SemanticStaticColorTable />

---

## 타이포그래피

PC·모바일 값이 동일한 고정 타이포 토큰입니다.

반응형 제목(`heading-xl / heading-l / heading-m`)은 **반응형** 페이지에서 확인하세요.

<SemanticTypoStyleTable />

---

## 간격

크기 그룹 별칭 토큰입니다. `m / l / xl` 그룹은 모바일에서 한 단계 작은 값으로 전환됩니다.

레이아웃 토큰(`section-padding-*`, `container-padding`)은 **반응형** 페이지에서 확인하세요.

<SpacingSizeTable />

---

아래 gap / padding / margin 토큰은 용도별 별칭으로, 향후 프리미티브로 대체될 예정입니다.
