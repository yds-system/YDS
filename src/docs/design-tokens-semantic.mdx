## 고정 색상

모드와 무관하게 항상 같은 값을 유지하는 색상 토큰입니다.

`mode.css`의 `--color-text-on-primary / --color-text-on-secondary`(모드별 가변)와 달리, 이 토큰은 어두운 채움(dark fill) 배경 위에서 항상 흰색으로 표시됩니다.

## 타이포그래피

`font-size` · `line-height`는 **반응형** 페이지에서 확인하세요. 여기에는 `font-weight` 시멘틱 토큰만 정의합니다.

| 토큰 이름 | 참조 | 값 | 용도 |
|---|---|---|---|
| `--font-weight-heading-xl` | `font-weight-bold` | 700 | XL 제목 |
| `--font-weight-heading-l` | `font-weight-bold` | 700 | L 제목 |
| `--font-weight-heading-m` | `font-weight-bold` | 700 | M 제목 |
| `--font-weight-heading-s` | `font-weight-bold` | 700 | S 제목 |
| `--font-weight-body-l` | `font-weight-regular` | 400 | L 본문 |
| `--font-weight-body-m` | `font-weight-regular` | 400 | M 본문 |
| `--font-weight-body-s` | `font-weight-regular` | 400 | S 본문 |
| `--font-weight-body-xs` | `font-weight-regular` | 400 | XS 본문 |

---

## 간격

간격 그룹(`space-xs-*` ~ `space-xl-*`)과 레이아웃 토큰(`section-padding-*`, `container-padding-x`, `padding-card-*`, `gap-layout-*`)은 모두 **반응형** 페이지에서 확인하세요.

아래 gap / padding / section-padding 토큰은 flex·grid 간격과 컴포넌트 내부 여백 용도별 별칭입니다.
