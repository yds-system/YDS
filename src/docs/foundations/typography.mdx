# Typography

타이포그래피

---

## 개요

기본 폰트는 **Pretendard GOV** (`font-family-base`)이며, 코드 블록에는 **D2Coding** (`font-family-code`)을 사용한다.

모든 rem 값은 `html { font-size: 62.5%; }` (KRDS `common.css` 기준)를 전제로 한다. 이 설정에서 `1rem = 10px`이다. 이 설정이 없으면 모든 토큰의 px 환산이 틀어진다.

```css
/* KRDS common.css — 전역에 반드시 포함 */
html { font-size: 62.5%; }
```

## 위계

### Heading

| 단계 | 토큰 | 크기 (PC) | 사용 |
|---|---|---|---|
| XL | `font-size-heading-xl` | 40px | 페이지 최상위 제목, 히어로 영역 |
| L | `font-size-heading-l` | 32px | 주요 섹션 제목 |
| M | `font-size-heading-m` | 24px | 서브 섹션 제목, 카드 그룹 제목 |
| S | `font-size-heading-s` | 19px | 컴포넌트 내부 소제목, 폼 그룹 제목 |

- <span style={{background:'#fff3cd',color:'#664d03',padding:'2px 8px',borderRadius:'4px',fontSize:'11px',fontWeight:700}}>팀 결정 필요</span> 한 페이지에서 Heading 단계를 건너뛰는 것(예: H1 다음 H3 사용)의 허용 여부와 HTML 시맨틱 요소(`<h1>`~`<h4>`)와 토큰 단계의 1:1 대응 여부를 정한다.

### Body

| 단계 | 토큰 | 크기 | 사용 |
|---|---|---|---|
| L | `font-size-body-l` | 19px | 리드 문단, 중요도 높은 본문 |
| M | `font-size-body-m` | 17px | 기본 본문 (default) |
| S | `font-size-body-s` | 15px | 보조 설명, 도움말 텍스트, 레이블 |
| XS | `font-size-body-xs` | 13px | 캡션, 태그 레이블, 뱃지 텍스트 |

- 본문의 기본값은 **Body M (17px)**이다. 별도 지정 없이 컴포넌트 내 텍스트는 이 크기로 fallback된다.
- <span style={{background:'#fff3cd',color:'#664d03',padding:'2px 8px',borderRadius:'4px',fontSize:'11px',fontWeight:700}}>팀 결정 필요</span> Body L을 본문 기본으로 쓰는 경우(예: 콘텐츠 중심 페이지)를 허용할지 여부.

### font-weight

| 값 | 토큰 | 사용 |
|---|---|---|
| 400 | `font-weight-regular` | 일반 본문 |
| 500 | `font-weight-medium` | 레이블, 버튼 텍스트, 중간 강조 |
| 700 | `font-weight-bold` | 제목, 주요 강조 |

- <span style={{background:'#fff3cd',color:'#664d03',padding:'2px 8px',borderRadius:'4px',fontSize:'11px',fontWeight:700}}>팀 결정 필요</span> `font-weight-medium`(500)은 KRDS에 없는 자체 추가 토큰이다. 400과 700 사이 어느 경우에 사용할지 적용 패턴을 정한다. (예: 버튼 텍스트는 700, 탭 레이블은 500)

## 사용 규칙

### 해야 할 것

- 텍스트 크기는 항상 **시멘틱 토큰**(`--font-size-heading-m`, `--font-size-body-m` 등)을 사용한다.
- 반응형 제목은 **responsive 토큰**(`--font-size-heading-xl` 등)을 사용하면 PC/모바일 값이 자동으로 전환된다. 별도 미디어 쿼리를 작성하지 않아도 된다.
- 행간은 `line-height-tight`(1.25, 큰 제목) · `line-height-normal`(1.5, 본문)을 용도에 맞게 사용한다.

### 하지 말 것

- `font-size: 16px`, `font-size: 1.6rem` 처럼 **값을 직접 지정**하지 않는다. 토큰 외부의 임의 크기를 추가하면 스케일 일관성이 깨진다.
- `--font-size-24`, `--font-size-17` 같은 **프리미티브 폰트 토큰을 컴포넌트에서 직접** 사용하지 않는다. 반드시 `heading-*` / `body-*` 시멘틱 토큰을 거쳐 참조한다.
- 본문 텍스트에 `line-height: 1` 또는 고정 px 행간을 쓰지 않는다. 브라우저 글꼴 확대 시 줄이 겹친다.
- <span style={{background:'#fff3cd',color:'#664d03',padding:'2px 8px',borderRadius:'4px',fontSize:'11px',fontWeight:700}}>팀 결정 필요</span> 마케팅·히어로 영역에서 Heading XL을 넘어서는 대형 텍스트가 필요할 경우의 처리 방법 (토큰 추가 vs. 로컬 오버라이드 허용 범위).

## 접근성

### 최소 글자 크기

| 용도 | 최소 크기 | 근거 |
|---|---|---|
| 일반 본문 | **15px** (body-s) | KRDS 권장 최소, 가독성 |
| 보조 텍스트 (캡션·뱃지) | **13px** (body-xs) | KRDS 최소 허용치 |
| 비활성(`disabled`) 텍스트 | 대비 면제, 크기 동일 | WCAG 2.1 1.4.3 예외 |

13px(body-xs) 미만 크기는 사용하지 않는다.

### 줄 간격

WCAG 2.1 성공 기준 1.4.12(텍스트 간격)에 따르면, 사용자가 줄 간격을 글자 크기의 1.5배로 조정해도 콘텐츠·기능을 잃지 않아야 한다. `line-height-normal`(1.5)이 이 기준을 충족한다. 고정 px 행간을 쓰면 사용자 확대 시 기준을 위반할 수 있다.

### 브라우저 글꼴 확대 대응

`html { font-size: 62.5%; }` 설정은 브라우저 기본 글꼴 크기(16px) 기반 확대를 그대로 따른다. 사용자가 브라우저 기본 글꼴을 20px로 올리면 `1rem = 12.5px`로 비례 확대된다. `px` 단위로 고정하면 이 확대가 무시되므로, 텍스트 크기는 반드시 `rem`을 사용한다.

```css
/* 올바른 예 — rem 사용 */
font-size: var(--font-size-body-m);   /* 1.7rem, 브라우저 확대에 반응 */

/* 잘못된 예 — px 고정 */
font-size: 17px;                      /* 브라우저 글꼴 확대 무시 */
```
