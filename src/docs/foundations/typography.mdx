# Typography

타이포그래피

---

## 개요

기본 폰트는 **Pretendard GOV** (`font-family-base`)이며, 코드 블록에는 **D2Coding** (`font-family-code`)을 사용한다. Pretendard GOV는 가변 굵기(100~900)를 지원하므로 `font-weight: 500`을 포함한 전 범위를 사용할 수 있다.

모든 rem 값은 `html { font-size: 62.5%; }` (KRDS `common.css` 기준)를 전제로 한다. 이 설정에서 `1rem = 10px`이다. 이 설정이 없으면 모든 토큰의 px 환산이 틀어진다.

```css
/* KRDS common.css — 전역에 반드시 포함 */
html { font-size: 62.5%; }
```

## 타입 스케일

### 텍스트 스타일

### SCSS 텍스트 스타일 믹스인

`src/styles/_typography.scss`에 위 스타일 조합을 믹스인으로 제공한다. 세 토큰을 개별로 작성하는 대신 믹스인 하나로 적용할 수 있다.

| 믹스인 | 크기 토큰 | 굵기 토큰 | 행간 토큰 |
|---|---|---|---|
| `text-display-l` | `font-size-display-l` | `font-weight-bold` | `line-height-heading-xl` |
| `text-display-m` | `font-size-display-m` | `font-weight-bold` | `line-height-heading-xl` |
| `text-display-s` | `font-size-display-s` | `font-weight-bold` | `line-height-heading-xl` |
| `text-heading-xl` | `font-size-heading-xl` | `font-weight-heading-xl` | `line-height-heading-xl` |
| `text-heading-l` | `font-size-heading-l` | `font-weight-heading-l` | `line-height-heading-l` |
| `text-heading-m` | `font-size-heading-m` | `font-weight-heading-m` | `line-height-heading-m` |
| `text-heading-s` | `font-size-heading-s` | `font-weight-heading-s` | `line-height-heading-s` |
| `text-body-l` | `font-size-body-l` | `font-weight-body-l` | `line-height-body-l` |
| `text-body-m` | `font-size-body-m` | `font-weight-body-m` | `line-height-body-m` |
| `text-body-s` | `font-size-body-s` | `font-weight-body-s` | `line-height-body-s` |
| `text-body-xs` | `font-size-body-xs` | `font-weight-body-xs` | `line-height-body-xs` |

```scss
/* 올바른 예 — 믹스인 사용 */
.yds-hero__title   { @include text-display-l; }
.yds-section__heading { @include text-heading-m; }
.yds-card__desc    { @include text-body-s; }

/* 잘못된 예 — 토큰을 개별로 반복 작성 */
.yds-hero__title {
  font-size:   var(--font-size-display-l); /* 반복 작성은 오류 발생 위험 */
  font-weight: 700;                        /* 하드코딩 금지 */
  line-height: 1.25;
}
```

## 위계

### Display

| 단계 | 토큰 | 크기 (PC) | 크기 (모바일) | 사용 |
|---|---|---|---|---|
| L | `font-size-display-l` | 60px | 44px | 히어로·랜딩 최대 타이틀 |
| M | `font-size-display-m` | 44px | 32px | 히어로·랜딩 중형 타이틀 |
| S | `font-size-display-s` | 36px | 28px | 주요 페이지 대형 제목 |

### Heading

| 단계 | 토큰 | 크기 (PC) | 크기 (모바일) | 사용 |
|---|---|---|---|---|
| XL | `font-size-heading-xl` | 40px | 28px | 페이지 최상위 제목 |
| L | `font-size-heading-l` | 32px | 24px | 주요 섹션 제목 |
| M | `font-size-heading-m` | 24px | 22px | 서브 섹션 제목, 카드 그룹 제목 |
| S | `font-size-heading-s` | 19px | 19px | 컴포넌트 내부 소제목, 폼 그룹 제목 |

**HTML 태그와 토큰의 관계**: HTML 제목 태그(`<h1>`~`<h4>`)는 문서 구조를 기준으로 순서대로 사용하며 단계를 건너뛰지 않는다. 토큰은 디자인 위계에 따라 독립적으로 고른다. 예: 카드 내부 소제목은 HTML `<h3>`이지만 토큰은 `font-size-heading-s`를 적용할 수 있다.

### Body

| 단계 | 토큰 | 크기 | 사용 |
|---|---|---|---|
| L | `font-size-body-l` | 19px | 약관·공지 상세·가이드 문서 등 긴 글 위주 페이지의 본문 기본 |
| M | `font-size-body-m` | 17px | 일반 UI의 기본 본문 (default) |
| S | `font-size-body-s` | 15px | 보조 설명, 도움말 텍스트, 레이블 |
| XS | `font-size-body-xs` | 13px | 캡션, 태그 레이블, 뱃지 텍스트 |

Body M(17px)이 기본이다. 약관·공지 상세 등 긴 글 위주 페이지에서는 Body L(19px)을 본문 기본으로 허용한다. 카드 본문·폼 도움말 등 일반 UI 컴포넌트에서는 Body M을 유지한다.

### font-weight

| 값 | 토큰 | 사용 |
|---|---|---|
| 400 | `font-weight-regular` | 일반 본문, 보조 텍스트 |
| 500 | `font-weight-medium` | 버튼·탭·라디오·체크박스 레이블 등 사용자가 직접 조작하는 UI 요소 텍스트 |
| 700 | `font-weight-bold` | Heading 전 단계, 주요 강조 텍스트 |

`font-weight-medium`(500)은 400(본문)과 700(제목) 사이의 중간 강조가 필요한 조작 요소에 사용한다. Pretendard GOV는 가변 굵기를 지원하므로 별도 폰트 파일 추가 없이 사용 가능하다.

## 사용 규칙

### 해야 할 것

- 텍스트 크기는 항상 **시멘틱 토큰**(`--font-size-heading-m`, `--font-size-body-m` 등)을 사용한다.
- 반응형 제목은 **responsive 토큰**(`--font-size-heading-xl` 등)을 사용하면 PC/모바일 값이 자동으로 전환된다. 별도 미디어 쿼리를 작성하지 않아도 된다.
- 행간은 `line-height-tight`(1.25, 큰 제목) · `line-height-normal`(1.5, 본문)을 용도에 맞게 사용한다.
- HTML 제목 태그는 `<h1>` → `<h2>` → `<h3>` → `<h4>` 순서를 지키고 단계를 건너뛰지 않는다.

### 하지 말 것

- `font-size: 16px`, `font-size: 1.6rem` 처럼 **값을 직접 지정**하지 않는다. 토큰 외부의 임의 크기를 추가하면 스케일 일관성이 깨진다.
- `--font-size-24`, `--font-size-17` 같은 **프리미티브 폰트 토큰을 컴포넌트에서 직접** 사용하지 않는다. 반드시 `heading-*` / `body-*` 시멘틱 토큰을 거쳐 참조한다.
- 본문 텍스트에 `line-height: 1` 또는 고정 px 행간을 쓰지 않는다. 브라우저 글꼴 확대 시 줄이 겹친다.
- **Heading XL(40px)보다 큰 텍스트**가 필요한 경우, `display-l/m/s` 토큰을 사용한다. 컴포넌트 내에서 임의 값을 직접 작성하지 않는다.

## 접근성

### 최소 글자 크기

| 용도 | 최소 크기 | 근거 |
|---|---|---|
| 일반 본문 | **15px** (body-s) | KRDS 권장 최소, 가독성 |
| 보조 텍스트 (캡션·뱃지) | **13px** (body-xs) | KRDS 최소 허용치 |
| 비활성(`disabled`) 텍스트 | 대비 면제, 크기 동일 | WCAG 2.1 1.4.3 예외 |

13px(body-xs) 미만 크기는 사용하지 않는다.

### 줄 간격

WCAG 2.1 성공 기준 1.4.12(텍스트 간격)에 따르면, 사용자가 줄 간격을 글자 크기의 1.5배로 조정해도 콘텐츠·기능을 잃지 않아야 한다. `line-height-normal`(1.5)이 이 기준을 충족한다. 고정 px 행간을 쓰면 사용자 확대 시 기준을 위반할 수 있다.

### 브라우저 글꼴 확대 대응

`html { font-size: 62.5%; }` 설정은 브라우저 기본 글꼴 크기(16px) 기반 확대를 그대로 따른다. 사용자가 브라우저 기본 글꼴을 20px로 올리면 `1rem = 12.5px`로 비례 확대된다. `px` 단위로 고정하면 이 확대가 무시되므로, 텍스트 크기는 반드시 `rem`을 사용한다.

```css
/* 올바른 예 — rem 사용 */
font-size: var(--font-size-body-m);   /* 1.7rem, 브라우저 확대에 반응 */

/* 잘못된 예 — px 고정 */
font-size: 17px;                      /* 브라우저 글꼴 확대 무시 */
```
