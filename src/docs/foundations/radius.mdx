# Radius

모서리

---

## 개요

모서리 반경 토큰은 **2계층 구조**로 관리된다.

| 계층 | 예시 | 역할 |
|---|---|---|
| 프리미티브 | `radius-8` | 원시 값 (rem 단위) |
| 시멘틱 | `radius-m` | 용도 기반 이름 (xs~circle) |

컴포넌트는 항상 **시멘틱 토큰**(`radius-xs` ~ `radius-circle`)을 사용한다. 프리미티브(`radius-8` 등)를 컴포넌트에서 직접 참조하지 않는다.

## 크기 그룹별 사용처

| 토큰 | 크기 | 사용처 |
|---|---|---|
| **radius-xs** | 2px | 현재 사용처 없음 |
| **radius-s** | 4px | 현재 사용처 없음 |
| **radius-m** | 8px | 카드, 로고, 썸네일 |
| **radius-l** | 12px | 현재 사용처 없음 |
| **radius-xl** | 16px | 현재 사용처 없음 |
| **radius-circle** | 999px+ | 현재 사용처 없음 |

## 사용 규칙

### 해야 할 것

- 컴포넌트에서는 항상 **시멘틱 토큰**(`--radius-m`, `--radius-l` 등)을 사용한다.
- 컴포넌트 내부 변수(`--yds-{component}--radius`)는 시멘틱 토큰을 참조해 선언한다.

```css
/* 올바른 예 — 시멘틱 토큰 참조 */
.yds-btn {
  --yds-btn--radius: var(--radius-m);
  border-radius: var(--yds-btn--radius);
}

.yds-card {
  --yds-card--radius: var(--radius-m);
  border-radius: var(--yds-card--radius);
}
```

- 원형·알약형이 필요한 경우 `radius-circle`을 사용한다. 큰 고정 값(`50%`, `999px`)을 직접 쓰지 않는다.

### 하지 말 것

- `border-radius: 8px`, `border-radius: 0.8rem` 처럼 **값을 직접 작성**하지 않는다.
- `--radius-8` 같은 **프리미티브 토큰을 컴포넌트에서 직접** 사용하지 않는다. 반드시 `radius-xs` ~ `radius-circle` 시멘틱 토큰을 거쳐 참조한다.
- 작은 요소(뱃지·태그)에 `radius-l` 이상을 쓰지 않는다. 의도치 않은 원형 왜곡이 발생한다.
- 토큰에 없는 중간 값(예: 3px, 5px, 10px)을 임의로 추가하지 않는다. 꼭 필요하면 토큰 추가를 먼저 논의한다.
