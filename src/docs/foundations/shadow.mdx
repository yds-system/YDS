# Shadow

그림자

---

## 개요

그림자 토큰은 **시멘틱 토큰**(`shadow-s`, `shadow-m`, `shadow-l`)만 사용한다. 프리미티브가 없고, 역할별로 바로 이름을 붙인 단일 계층 구조다.

그림자는 두 레이어로 구성된다. 첫 레이어(2px 확산)는 테두리 보정용이고, 둘째 레이어가 실제 깊이감을 표현한다. 색상은 `--color-shadow-subtle`과 `--color-shadow-default` 토큰을 참조한다.

```css
/* 그림자 색상 토큰 (mode.css에 정의, 모든 모드 동일) */
--color-shadow-subtle:  rgba(0, 0, 0, 0.10);  /* 첫 레이어·얕은 그림자 */
--color-shadow-default: rgba(0, 0, 0, 0.25);  /* 깊은 그림자 두 번째 레이어 */
```

## 깊이 단계별 사용처

| 토큰 | 깊이 | 주요 사용처 |
|---|---|---|
| **shadow-none** | 없음 | 그림자 초기화, hover 전 상태, 테두리형 카드 |
| **shadow-s** | 얕음 | 카드 기본 상태, 슬라이드 박스, 썸네일 |
| **shadow-m** | 중간 | 카드 hover 상태, 드롭다운, 툴팁 |
| **shadow-l** | 깊음 | 모달·다이얼로그, 풀스크린 오버레이 |

**원칙**: 같은 영역에서 그림자 단계가 많을수록 시각적 소음이 커진다. 한 화면에 `shadow-l`은 모달 1개에만 사용하는 것이 원칙이다.

## 사용 규칙

### 해야 할 것

- 항상 **시멘틱 토큰**(`--shadow-s`, `--shadow-m`, `--shadow-l`)을 사용한다.
- 카드는 기본 상태에서 `shadow-s`, hover 시 `shadow-m`으로 전환한다.

```css
/* 올바른 예 — 토큰 참조 + hover 전환 */
.ds-card {
  box-shadow: var(--shadow-s);
  transition: box-shadow 0.15s ease;
}
.ds-card:hover {
  box-shadow: var(--shadow-m);
}
```

- 그림자를 제거해야 할 때는 `shadow-none`을 사용한다. `box-shadow: none`을 직접 쓰지 않는다.

### 하지 말 것

- `box-shadow: 0 4px 8px rgba(0,0,0,0.1)` 처럼 **값을 직접 작성**하지 않는다. 색상이 모드에 따라 바뀌지 않는다.
- 그림자 색상을 `rgba` 값으로 고정하지 않는다. `--color-shadow-subtle` / `--color-shadow-default` 토큰을 참조한다.
- 같은 화면에 `shadow-l`을 여러 개 사용하지 않는다. 모달 외 요소에 `shadow-l`이 필요하다면 디자인을 재검토한다.
- 텍스트에 `text-shadow`를 사용하지 않는다. 접근성(가독성·대비) 보장이 어렵다.
