# Spacing

간격

---

## 개요

간격 토큰은 **4px 배수 체계**를 따른다. `1rem = 10px`(html 62.5%) 기준에서 `0.4rem = 4px`가 최소 단위이며, 모든 여백·간격은 이 배수 위에서 표현한다.

토큰은 세 계층으로 구성된다.

| 계층 | 예시 | 역할 |
|---|---|---|
| 프리미티브 | `space-16` | 원시 값 (0.4rem 단위) |
| 별칭 | `space-s-16` | 크기 그룹(xs~xl) + 값 조합 |
| 시멘틱 | `gap-m`, `padding-s` | 용도 기반 이름 |

컴포넌트는 **시멘틱 토큰 → 별칭 토큰** 순으로 먼저 고려한다. 해당하는 시멘틱이 없을 때만 별칭을 직접 참조한다.

## 크기 그룹별 사용처

| 그룹 | 범위 | 주요 사용처 |
|---|---|---|
| **xs** | 2–8px | 아이콘↔레이블 사이, 아이콘 내부 여백, 뱃지 패딩, 인라인 소간격 |
| **s** | 12–20px | 버튼 패딩, 입력 필드 내부 여백, 카드 콘텐츠 내부, 리스트 항목 패딩 |
| **m** | 24–32px | 컴포넌트 간 간격, 그리드 열 간격(gutter), 폼 행 간격 |
| **l** | 40–48px | 섹션 패딩(좌우·상하), 카드 그룹 간격, 페이지 콘텐츠 영역 패딩 |
| **xl** | 64–80px | 섹션 간 여백, 페이지 최상단·최하단 여백, 히어로 섹션 패딩 |

**그룹 경계 원칙**: xs·s는 컴포넌트 내부에 사용하고, m·l·xl은 컴포넌트 사이·섹션 수준에 사용한다. 버튼 패딩에 xl을 쓰거나, 섹션 간격에 xs를 쓰지 않는다.

## 사용 규칙

### 해야 할 것

- 모든 간격은 토큰을 사용한다. 토큰에 없는 중간 값이 필요하면 가장 가까운 토큰을 사용하거나 토큰 추가를 먼저 논의한다.
- 반응형이 필요한 m·l·xl 그룹은 `space-m-24`, `space-l-40` 같은 반응형 별칭 토큰을 사용한다. 별도 미디어 쿼리를 작성하지 않아도 모바일 뷰포트에서 자동으로 축소된다.
- 컴포넌트 내부 변수(`--ds-{component}--padding` 등)는 시멘틱·별칭 토큰을 참조해 선언한다.

```css
/* 올바른 예 — 별칭 토큰 참조 */
.ds-card {
  --ds-card--padding: var(--space-s-16);
  padding: var(--ds-card--padding);
}

/* 올바른 예 — 시멘틱 토큰 참조 */
.ds-btn-group {
  gap: var(--gap-s);
}
```

### 하지 말 것

- `padding: 16px`, `gap: 1.6rem` 처럼 **값을 직접 작성**하지 않는다. 값이 같더라도 토큰을 통해 참조한다.
- 4px 배수가 아닌 임의 값(예: 6px, 10px, 15px)을 추가하지 않는다. 꼭 필요하면 토큰 추가를 먼저 논의한다.
- xs·s 그룹 토큰을 섹션 간 여백에 사용하지 않는다. 반대로 xl 토큰을 버튼 내부 패딩에 쓰지 않는다.
- 반응형 별칭 토큰(예: `space-m-24`)을 사용하고 그 위에 별도 미디어 쿼리로 같은 속성을 덮어쓰지 않는다. 반응형 로직이 토큰에 내장되어 있으므로 중복 쿼리는 버그의 원인이 된다.
