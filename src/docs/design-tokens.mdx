# 디자인 토큰

디자인 토큰은 색상·타이포·간격·모서리 같은 시각적 결정을 코드로 표현한 이름 붙은 변수입니다.
컴포넌트는 값을 직접 쓰지 않고 토큰 이름만 참조합니다.

---

## 디자인 토큰 요소

| 분류 | 페이지 |
|---|---|
| 색상 | 디자인 토큰 정의서 / 색상 |
| 타이포그래피 | 디자인 토큰 정의서 / 타이포그래피 |
| 간격 | 디자인 토큰 정의서 / 간격 |
| 라운드 | 디자인 토큰 정의서 / 라운드 |
| 그림자 | 디자인 토큰 정의서 / 그림자 |

---

## 네이밍 규칙

```
--{분류}-{대상}-{역할}
```

**피그마 ↔ 코드 변환 규칙**: Figma 변수 이름에서 `/`를 `-`로 바꾸면 CSS 변수 이름이 된다.

> `color/bg/primary` → `--color-bg-primary` &nbsp;/&nbsp; `color/gray/90` → `--color-gray-90`

**프리미티브는 물감, 시멘틱은 용도가 적힌 물감통.**
색칠할 때는 물감통(시멘틱)을 집어든다. 내부에 무슨 물감(프리미티브)이 들어 있는지는 몰라도 된다.
테마를 바꿀 때는 물감통에 다른 물감을 채워 넣으면(오버라이드) 모든 컴포넌트가 자동으로 바뀐다.

**장식 vs UI 사용 구분**

- **아이콘·일러스트·차트 등 장식** → 프리미티브 직접 참조 허용 (`--color-primary-50`, `--color-success-30` 등)
- **버튼·텍스트·배경·테두리 등 UI** → 반드시 시멘틱 참조 (`--color-bg-primary`, `--color-text-default` 등)

## 테마 비교: 기본 vs project-a

`[data-theme="project-a"]`에서 `color-primary-*` **프리미티브 값 자체**를 초록 계열로 덮어씁니다.
이 프리미티브를 `var()`로 참조하는 `color-bg-primary`, `color-text-primary`, `color-border-focus` 등
모든 시멘틱 토큰이 자동으로 바뀝니다.

```html
<html lang="ko" data-theme="project-a">
```
