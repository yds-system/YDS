# 디자인 토큰

디자인 토큰은 색상·타이포·간격·모서리 같은 시각적 결정을 코드로 표현한 이름 붙은 변수입니다.
컴포넌트는 값을 직접 쓰지 않고 토큰 이름만 참조합니다.

---

## 네이밍 규칙

```
--{분류}-{대상}-{역할}
```

**프리미티브는 물감, 시멘틱은 용도가 적힌 물감통.**
색칠할 때는 물감통(시멘틱)을 집어든다. 내부에 무슨 물감(프리미티브)이 들어 있는지는 몰라도 된다.
테마를 바꿀 때는 물감통에 다른 물감을 채워 넣으면(오버라이드) 모든 컴포넌트가 자동으로 바뀐다.

**장식 vs UI 사용 구분**

- **아이콘·일러스트·차트 등 장식** → 프리미티브 직접 참조 허용 (`--primary-50`, `--success-30` 등)
- **버튼·텍스트·배경·테두리 등 UI** → 반드시 시멘틱 참조 (`--bg-primary`, `--txt-default` 등)

## 4. 간격

### 간격 사용 규칙

- **방향을 토큰 이름에 넣지 않는다.** `--gap-top-m` 같은 이름 대신 CSS 속성에서 방향을 지정한다. (`margin-top: var(--margin-m)`)
- **스케일**: xs → s → m → l → xl. 범위를 벗어나면 2xs / 2xl로 확장한다.
- **일회성 특수값**은 시멘틱 토큰 대신 프리미티브(`--space-12`)를 직접 사용해도 된다.
- **Figma 연동**: `gap-*` 는 Figma "gap" scope, `padding-*` 는 "padding" scope에 매핑한다.

| 그룹 | 용도 |
|---|---|
| `gap-xs~xl` | flex·grid 아이템 사이 간격 |
| `padding-xs~xl` | 컴포넌트 내부 여백 |
| `margin-xs~xl` | 블록 간 외부 여백 (gap보다 한 단계 큰 값) |
| `section-padding-s/m/l` | 섹션 상하 여백 (모바일에서 자동 축소) |
| `container-padding` | 페이지 좌우 여백 (모바일에서 자동 축소) |

## 5. 그림자

그림자는 **elevation(높이감)** 을 표현합니다. 레이어가 위로 올라올수록 s → m → l 단계를 씁니다.

**사용 규칙**

- **카드**: 기본 `shadow-s`, hover 시 `shadow-m`으로 전환한다.
- **드롭다운·툴팁**: `shadow-m`
- **모달**: `shadow-l`
- **그림자가 없어야 하는 경우** (예: flat 테이블 행): `shadow-none`을 명시적으로 사용한다.

**Figma 연동**: Figma에서 Effect Style을 `shadow/s`, `shadow/m`, `shadow/l` 이름으로 만들어 연결한다.
