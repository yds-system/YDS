# Token Overview

디자인 토큰

디자인 토큰은 색상·타이포·간격·모서리 같은 시각적 결정을 코드로 표현한 이름 붙은 변수입니다.
컴포넌트는 값을 직접 쓰지 않고 토큰 이름만 참조합니다.

---

## 4계층 토큰 구조

| 계층 | 파일 | 역할 |
|---|---|---|
| **프리미티브** | `primitive.css` | 원재료 (색상·폰트·간격·모서리 원시 값) |
| **반응형** | `responsive.css` | 뷰포트별 가변 토큰 + font-size·line-height 전체. PC 기본값을 `:root`에, 모바일 덮어쓰기를 `@media` 블록에 정의. |
| **모드** | `mode.css` | 색상 모드별 가변 토큰 (라이트·다크·고대비·시스템) |
| **시멘틱** | `semantic.css` | 용도 기반 고정 토큰 (프리미티브·반응형·모드 참조) |

**참조 방향**: `semantic / responsive / mode` → `primitive`

역방향(예: `primitive`가 `semantic`을 참조) 금지.

---

## 로드 순서

```
primitive.css   → 원재료 (색상·크기·폰트·간격·모서리 원시 값)
responsive.css  → 반응형 (PC 기본값 + @media 모바일 덮어쓰기)
mode.css        → 모드 색상 (라이트·다크·고대비·시스템)
semantic.css    → 시멘틱 (고정 타이포·간격·그림자·모서리 별칭)
```

---

**피그마 ↔ 코드 변환 규칙**: Figma 변수 이름에서 `/`를 `-`로 바꾸면 CSS 변수 이름이 된다.

> `color/bg/primary` → `--color-bg-primary` &nbsp;/&nbsp; `color/gray/90` → `--color-gray-90`

**프리미티브는 물감, 시멘틱은 용도가 적힌 물감통.**
색칠할 때는 물감통(시멘틱)을 집어든다. 내부에 무슨 물감(프리미티브)이 들어 있는지는 몰라도 된다.
테마를 바꿀 때는 물감통에 다른 물감을 채워 넣으면(오버라이드) 모든 컴포넌트가 자동으로 바뀐다.

**장식 vs UI 사용 구분**

- **아이콘·일러스트·차트 등 장식** → 프리미티브 직접 참조 허용 (`--color-primary-50`, `--color-success-30` 등)
- **버튼·텍스트·배경·테두리 등 UI** → 반드시 모드·시멘틱 참조 (`--color-bg-primary`, `--color-text-default` 등)
