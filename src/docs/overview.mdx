# 윤컴 디자인 시스템

범정부 UI/UX 디자인 시스템(KRDS)을 기반으로 한 윤컴디자인 공식 디자인 시스템입니다.
기획자·디자이너·퍼블리셔·개발자가 함께 사용할 수 있도록 토큰·컴포넌트·가이드를 한 곳에 제공합니다.

---

## 섹션 안내

**Brand** — 로고 등 브랜드 아이덴티티 에셋과 사용 규칙을 제공합니다.

**Foundations** — 색상·타이포그래피·간격·레이아웃·모서리·그림자·접근성·아이코노그래피 등 모든 컴포넌트가 공유하는 시각적 기반을 정의합니다.

**Components** — KRDS 기반 UI 컴포넌트를 가나다순으로 제공합니다. 각 컴포넌트 페이지에서 Playground와 All Variants 스토리를 확인할 수 있습니다.

**Tokens** — 디자인 토큰 구조(프리미티브·모드·반응형·시멘틱)와 각 레이어의 정의를 설명합니다.

**Patterns** — 여러 컴포넌트를 조합한 페이지 레벨 레이아웃 패턴을 제공합니다.
