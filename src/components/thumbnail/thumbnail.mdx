# Thumbnail

썸네일

콘텐츠 영역에 삽입되는 이미지를 비율·크기별로 표시하는 컴포넌트입니다.  
라벨·배지 오버레이 자리를 제공하며, 로딩·실패 상태를 처리합니다.

> **원칙**: 정해진 비율(`--1x1 · --4x3 · --16x9`)과 크기(`--xs ~ --xl`)만 사용합니다. 스타일을 임의로 변경하지 않습니다.

---

## 개요

- **블록**: `ds-thumbnail`
- **KRDS 원본**: KRDS 이미지 기준 적용, 라벨·배지·크기 modifier는 자체 추가

## 언제 사용하는지

- 카드·게시글·갤러리에서 이미지를 비율 고정으로 삽입할 때
- 프로필 사진·아바타처럼 원형 고정 크기 이미지가 필요할 때
- 이미지 위에 NEW·HOT 라벨, 카운트 배지를 겹쳐야 할 때

## 사용하지 말아야 할 때

- 로고·아이콘처럼 잘리지 않게 전체를 보여줘야 하는 이미지는 `ds-logo` 또는 `ds-icon`을 사용한다.
- 정해진 비율·크기 외의 임의 크기를 적용해야 한다면, `ds-thumbnail`을 사용하지 않고 직접 `<img>`를 사용한다.

## 접근성

- **`alt` 필수**: 의미 있는 이미지는 반드시 내용을 설명하는 대체 텍스트를 제공한다.
- **장식 이미지**: 순수 장식 목적이면 `alt=""`로 설정해 스크린 리더가 건너뛰도록 한다.
- **원형 썸네일**: 모양이 바뀌어도 대체 텍스트 의미는 동일하게 유지한다.
- 배경 이미지(`background-image`)로 처리하면 스크린 리더가 읽지 못하므로, 콘텐츠 이미지는 반드시 `<img>` 태그를 사용한다.
