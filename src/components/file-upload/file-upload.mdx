# 파일 업로드 (File Upload)

## 개요

파일을 선택하거나 드래그 앤 드롭으로 첨부하는 폼 요소입니다.  
첨부 목록에서 업로드 중 / 완료 / 오류 상태를 시각적으로 구분하고, 개별 삭제 및 전체 삭제를 지원합니다.

---

## 네이밍

> KRDS 구성을 기준으로 ds- BEM 규칙에 따라 이름을 붙였습니다. KRDS 원본 클래스는 표의 'KRDS 원본' 열을 참고하세요.

## 언제 사용하는지

- 민원 신청, 게시판, 폼 등에서 **파일을 첨부**해야 할 때
- 허용 형식·용량 안내와 함께 **가이드 메시지**가 필요할 때
- 복수 파일 첨부가 필요하거나, 첨부 수 제한이 있을 때

---

## 사용하지 말아야 할 때

- 이미지 한 장만 업로드하는 단순 프로필 사진 입력에는 전용 UI를 검토한다.
- 파일 선택 없이 단순 버튼 한 개만 필요한 경우 `<input type="file">`을 직접 사용한다.

## JavaScript

드래그 앤 드롭과 파일 삭제는 JS로 처리합니다.

```js
const dropZone = document.querySelector('.ds-file-upload__dropzone');
const inputFile = document.querySelector('input[type="file"]');

// 파일 선택 버튼 → input 연결
dropZone.querySelector('button').addEventListener('click', () => inputFile.click());

// 드래그 오버
dropZone.addEventListener('dragover', (e) => {
  e.preventDefault();
  dropZone.classList.add('ds-file-upload__dropzone--dragover');
});

// 드래그 이탈
dropZone.addEventListener('dragleave', (e) => {
  if (!dropZone.contains(e.relatedTarget)) {
    dropZone.classList.remove('ds-file-upload__dropzone--dragover');
  }
});

// 드롭
dropZone.addEventListener('drop', (e) => {
  e.preventDefault();
  dropZone.classList.remove('ds-file-upload__dropzone--dragover');
  const files = e.dataTransfer.files;
  // 파일 처리 로직 추가
});
```

## 접근성

- `<input type="file">`과 `<label>`의 `for`·`id`를 반드시 연결한다.
- 파일 선택 버튼에 `tabindex="-1"`, `aria-hidden="true"`를 설정하고, 실제 포커스는 `<label>`이 받도록 한다.
- 드래그 앤 드롭 영역에 `role="region"`, `aria-label`을 부여해 보조기기가 영역을 인식하도록 한다.
- 업로드 중 스피너에 `role="status"`와 `.sr-only` 텍스트("업로드 중")를 제공한다.
- 완료 아이콘(`.ds-file-upload__item-icon--completed`)은 `<em class="sr-only">업로드 완료</em>`로 상태를 전달한다.
- 삭제 버튼에 `aria-label="파일명 삭제"` 형식으로 대상 파일을 명시한다.
- 오류 메시지(`.ds-file-upload__item-hint`)는 해당 `<li>` 내부에 위치해 맥락을 유지한다.
