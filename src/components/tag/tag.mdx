# 태그 (Tag)

선택된 필터·키워드를 칩 형태로 표시하고 삭제할 수 있는 요소입니다.  
필터 목록, 검색 조건, 선택된 항목 등 **사용자가 선택한 값을 시각적으로 확인하고 제거**할 때 사용합니다.

---

## 개요

- **블록**: `ds-tag-group`
- **태그 항목**: `ds-tag`
- **KRDS 원본**: `krds-tag-wrap` / `krds-btn-tag`

## 언제 사용하는지

- 검색·필터에서 **선택된 조건을 태그로 표시**하고 개별 삭제가 필요할 때
- 여러 키워드·카테고리를 가로로 나열해 표시할 때
- 클릭 가능한 분류 링크(링크 태그)를 나열할 때

## 사용하지 말아야 할 때

- 단순 상태·카테고리 표시에는 배지(Badge) 컴포넌트를 사용한다.
- 체크박스/라디오 형식의 선택 칩에는 Form Chip 컴포넌트를 사용한다.

## 접근성

- 삭제 버튼(`.ds-tag__delete-btn`)에는 `<span class="sr-only">태그명 삭제</span>`를 반드시 포함해 스크린리더가 어떤 태그를 삭제하는지 알 수 있도록 한다.
- 링크 태그(`<a class="ds-tag ds-tag--link">`)는 실제 이동 경로(`href`)를 제공한다.
- 태그 삭제 후 포커스가 자연스럽게 다음 태그 또는 컨테이너로 이동하도록 JS에서 관리한다.
- `.ds-tag-group`에 `aria-label="선택된 필터"` 등을 추가하면 보조기기 사용자가 맥락을 파악하기 쉽다.
