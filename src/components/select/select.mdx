# Select

선택 상자

## 개요

미리 정의된 선택지 중 **하나를 드롭다운으로 선택**하는 폼 요소입니다.  
`yds-form-group` 공유 구조(라벨·도움말·에러 메시지)를 그대로 사용합니다.

## 언제 사용하는지

- 선택지가 **5개 이상**으로 많아 화면에 모두 펼치기 어려울 때
- 선택지가 자주 바뀌거나 동적으로 로드되는 경우
- 화면 공간이 제한적이어서 라디오 버튼보다 간결하게 표시해야 할 때

---

## 사용하지 말아야 할 때

- 선택지가 **4개 이하**이고 공간이 충분하면 라디오 버튼이 더 직관적이다.
- 다중 선택이 필요하면 체크박스 또는 멀티 셀렉트를 사용한다.
- 선택지가 단 2개(예/아니오)인 경우에는 라디오 버튼이나 Toggle을 사용한다.

## HTML 구조

```html
<div class="yds-form-group">
  <div class="yds-form-label">
    <label for="id">레이블 <span class="yds-form-label__required" aria-hidden="true">필수</span></label>
  </div>
  <div class="yds-form-content">
    <select id="id" class="yds-select [yds-select--small|yds-select--medium] [yds-select--error]"
            title="선택하세요" [disabled]>
      <option value="">선택하세요</option>
      <option value="1">항목 1</option>
      <option value="2">항목 2</option>
    </select>
  </div>
  <p class="[yds-form-hint|yds-form-hint yds-form-hint--error]">메시지</p>
</div>
```

> 클래스명 목록은 위 **네이밍** 섹션을 참고한다. `title` 속성은 `<select>`의 접근성 이름을 제공하며 placeholder 역할을 한다.

### 상태

<Canvas of={SelectStories.상태} />

```html
<!-- 선택 완료 (JS로 completed 클래스 토글) -->
<select class="yds-select yds-select--completed" title="선택하세요"
  onchange="this.classList.toggle('yds-select--completed', !!this.value)">
  <option value="">선택하세요</option>
  <option value="1" selected>항목 1</option>
</select>

<!-- 에러 -->
<select class="yds-select yds-select--error" title="선택하세요">
  <option value="">선택하세요</option>
</select>
<p class="yds-form-hint yds-form-hint--error">항목을 선택해 주세요.</p>

<!-- 비활성화 -->
<select class="yds-select" title="선택하세요" disabled>
  <option value="">선택하세요</option>
</select>
```

> 선택 전에는 플레이스홀더처럼 흐린 색으로 표시되고,  
> 값이 선택되면 JS로 `.yds-select--completed` 클래스를 추가해 텍스트 색상을 바꿉니다.

## 접근성

- `<label>`의 `for`와 `<select>`의 `id`를 반드시 연결한다.
- `title` 속성으로 셀렉트의 접근성 이름을 제공한다 (placeholder 역할).
- 필수 입력은 `<select required>`와 시각적 표시(`.yds-form-label__required`)를 모두 제공한다.
- 에러 메시지는 `aria-describedby`로 셀렉트와 연결하면 스크린리더가 자동으로 읽는다.
- `disabled` 상태의 셀렉트는 키보드 포커스에서 제외되므로, 필요 시 `aria-disabled="true"`를 사용한다.
