# Text Input

텍스트 입력

## 개요

사용자가 텍스트를 직접 입력하는 폼 요소입니다.  
라벨·도움말·에러 메시지를 포함한 `yds-form-group` 구조는 체크박스·라디오·셀렉트 등 **모든 폼 요소에서 공통으로 재사용**합니다.

## 언제 사용하는지

- 이름, 주소, 이메일 등 **자유 텍스트 입력**이 필요할 때
- 선택지가 아닌 사용자 고유값을 받아야 할 때
- 비밀번호, 검색어, 전화번호 등 특정 입력 형식이 필요할 때

---

## 사용하지 말아야 할 때

- 선택지가 명확히 정해져 있다면 셀렉트 또는 라디오 버튼을 사용한다.
- 긴 서술형 입력에는 Textarea를 사용한다.
- 날짜 선택에는 Date Input 컴포넌트를 사용한다.

## HTML 구조

```html
<div class="yds-form-group">
  <div class="yds-form-label">
    <label for="id">레이블 <span class="yds-form-label__required" aria-hidden="true">필수</span></label>
  </div>
  <div class="yds-form-content [yds-form-content--error|yds-form-content--success|yds-form-content--info]">
    <input type="text" id="id" class="yds-input [yds-input--small|yds-input--medium]"
           placeholder="..." [disabled] [readonly]>
  </div>
  <p class="[yds-form-hint|yds-form-hint yds-form-hint--error|yds-form-hint yds-form-hint--success|yds-form-hint yds-form-hint--info]">메시지</p>
</div>
```

> 클래스명 목록은 위 **네이밍** 섹션을 참고한다.

## 접근성

- `<label>`의 `for` 속성과 `<input>`의 `id`를 반드시 연결한다.
- 필수 입력은 `<input required>`와 시각적 표시(`.yds-form-label__required`) 모두 제공한다.
- 에러 메시지는 `aria-describedby`로 연결하거나 포커스 이동으로 안내한다.
- `disabled` 입력은 스크린리더에 "비활성화"로 읽히므로 안내 문구를 별도 제공하지 않아도 된다.
- `readonly`는 `[readonly]` 속성으로, 포커스는 유지된다.

## yds-form-group 공유 구조

`yds-form-group.css`는 텍스트 입력 외에도 아래 컴포넌트에서 동일하게 사용한다.

| 컴포넌트 | 비고 |
|---|---|
| 체크박스 (Checkbox) | `yds-form-content` 내부 구조만 다름 |
| 라디오 버튼 (Radio Button) | `yds-form-content` 내부 구조만 다름 |
| 셀렉트 (Select) | `yds-form-content` 내부 구조만 다름 |
| 텍스트 영역 (Textarea) | `yds-textarea` 블록 추가 |
| 날짜 입력 (Date Input) | `calendar-conts` 추가 |
| 파일 업로드 (File Upload) | 별도 레이아웃 |
