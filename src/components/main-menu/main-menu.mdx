# 메인 메뉴 (Main Menu)

## 개요

사이트의 주요 메뉴(GNB)를 담당하는 컴포넌트입니다.
PC에서는 메가 메뉴(ds-main-menu), 모바일에서는 슬라이드 패널(ds-main-menu-mobile)로 표시됩니다.

---

## 네이밍

> KRDS 구성을 기준으로 ds- BEM 규칙에 따라 이름을 붙였습니다. KRDS 원본 클래스는 표의 'KRDS 원본' 열을 참고하세요.

## 사용 기준

- PC(≥1280px)에서는 헤더 하단에 ds-main-menu가 표시됩니다.
- 모바일(1280px 미만)에서는 전체 메뉴 버튼을 클릭하면 ds-main-menu-mobile 슬라이드 패널이 열립니다.
- 1depth → 2depth → 3depth 메가 메뉴 구조를 지원합니다.
