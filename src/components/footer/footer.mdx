# Footer

푸터

## 개요

사이트 하단에 위치하는 푸터 컴포넌트입니다.
관련 사이트 바로가기, 기관 정보, SNS 링크, 저작권 등으로 구성됩니다.

---

## 네이밍

> KRDS 구성을 기준으로 ds- BEM 규칙에 따라 이름을 붙였습니다. KRDS 원본 클래스는 표의 'KRDS 원본' 열을 참고하세요.

## 언제 사용하는지

- 모든 페이지 하단에 공통으로 배치합니다.
- 기관 정보, 관련 사이트 바로가기, SNS 링크, 저작권 등을 제공해야 할 때 사용합니다.
