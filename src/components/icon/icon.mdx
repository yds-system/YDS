## KRDS 아이콘 사용 방식 분석

### 방식: 개별 SVG + CSS mask-image (스프라이트 미사용)

KRDS는 아이콘 스프라이트(sprite) 또는 인라인 SVG를 사용하지 않습니다.  
각 아이콘이 독립된 `.svg` 파일로 제공되며, **CSS `mask-image`** 로 로드합니다.

| 항목 | 내용 |
|---|---|
| 파일 위치 | `/img/component/icon/*.svg` |
| HTML 마크업 | `<i class="ds-icon ds-ico-*">` |
| 색상 제어 | `background-color` (mask 방식) |
| 파일 수 | 약 90개 SVG |

### 두 가지 렌더 방식

#### ① mask 방식 (기본 · 단색 아이콘)

`mask-image`로 SVG를 마스크로 사용하고 `background-color`로 색상을 칠합니다.  
부모 요소의 색상을 상속받거나 CSS로 자유롭게 변경할 수 있습니다.

```css
.ds-icon.ds-ico-sch {
  -webkit-mask-image: url(/img/component/icon/ico_sch.svg);
  mask-image: url(/img/component/icon/ico_sch.svg);
  /* background-color 로 색상 변경 */
}
```

#### ② pure 방식 (SVG 원본 색상 유지)

`background-image`로 SVG를 불러와 **원본 색상을 그대로** 표시합니다.  
상태·알림 아이콘처럼 특정 색상이 의미를 가지는 경우에 사용합니다.

```css
.ds-icon.ds-ico-success-fill {
  background-image: url(/img/component/icon/ico_success_fill.svg);
  background-color: transparent !important;
  -webkit-mask: none;
  mask: none;
}
```

**pure 방식 아이콘**: `ds-ico-help`, `ds-ico-success-fill`, `ds-ico-information-fill`, `ds-ico-error-fill`, `ds-ico-complete-fill`, `ds-ico-flag`, `ds-ico-delete-fill`

## HTML 마크업

### 장식용 아이콘 (decorative)

주변 텍스트로 의미가 전달될 때. 스크린리더가 읽지 않습니다.

```html
<i class="ds-icon ds-ico-sch" aria-hidden="true"></i>
```

### 의미 있는 아이콘 (semantic)

아이콘만으로 의미를 전달할 때. 두 가지 방법 중 하나를 선택합니다.

```html
<!-- 방법 1: role + aria-label -->
<i class="ds-icon ds-ico-sch" role="img" aria-label="검색"></i>

<!-- 방법 2: sr-only (버튼 내부에서 권장) -->
<button type="button">
  <i class="ds-icon ds-ico-sch" aria-hidden="true"></i>
  <span class="sr-only">검색</span>
</button>
```

## 크기

아이콘 크기는 `--krds-icon--size-*` CSS 변수로 제어합니다.  
독립 사용 시 size 클래스를 추가하고, 컴포넌트 내에서는 컴포넌트 CSS가 크기를 지정합니다.

| 클래스 | CSS 변수 | 크기 |
|---|---|---|
| `ds-icon--xsmall` | `--krds-icon--size-xsmall` | `--krds-size-height-2` |
| `ds-icon--small`  | `--krds-icon--size-small`  | `--krds-size-height-2` |
| `ds-icon--medium` | `--krds-icon--size-medium` | `--krds-size-height-3` |
| (기본)             | `--krds-icon--size-large`  | `--krds-size-height-4` |
| `ds-icon--xlarge` | `--krds-icon--size-xlarge` | `--krds-size-height-4` |

## 접근성 가이드

- 아이콘이 **장식용**인 경우(주변 텍스트가 의미를 설명): `aria-hidden="true"`를 추가한다.
- 아이콘이 **단독으로 의미를 전달**하는 경우: `role="img" aria-label="설명"`을 추가하거나, 버튼 내부에 `<span class="sr-only">설명</span>`을 함께 작성한다.
- 아이콘 전용 버튼에서는 `aria-label`보다 **sr-only 패턴을 권장**한다. 번역이 쉽고 DOM에서 직접 확인 가능하기 때문이다.
- `<i>` 요소는 의미 없는 인라인 요소이며 KRDS에서 아이콘 컨테이너로 사용한다. 대체 가능한 요소로 `<span>`도 사용할 수 있다.
- pure 방식 아이콘(성공·오류·완료 등)은 색상 자체가 의미를 가지므로, 색상 외에 **텍스트나 레이블로 의미를 보완**해야 한다.
