# 체크박스 (Checkbox)

## 개요

사용자가 여러 항목 중 **하나 이상을 자유롭게 선택**할 수 있는 폼 요소입니다.  
라디오 버튼과 함께 `ds-check-item` 구조를 공유하며, `ds-form-group` 레이아웃 위에 구성됩니다.

## 언제 사용하는지

- 여러 항목 중 **0개 이상 다중 선택**이 가능할 때
- "전체 동의"와 같이 **하나의 항목을 독립적으로 토글**할 때
- 선택 여부를 즉시 적용하는 설정(알림, 필터 등)에 사용할 때

### 체크박스 vs 라디오 버튼

| 기준 | 체크박스 | 라디오 버튼 |
|---|---|---|
| 선택 수 | 0개 이상 다중 선택 | 반드시 1개 단일 선택 |
| 선택 취소 | 가능 (클릭으로 해제) | 불가 (다른 항목 선택으로만 변경) |
| 독립성 | 각 항목이 독립적 | 같은 `name` 그룹 내 연동 |
| 대표 예시 | 이용약관 동의, 관심사 선택 | 성별, 결제 수단, 정렬 기준 |

---

## 사용하지 말아야 할 때

- 선택지가 **반드시 하나**여야 할 때 → 라디오 버튼을 사용한다.
- 단순 On/Off 토글에는 Toggle(Switch) 컴포넌트를 검토한다.
- 선택지가 4개 이상이고 화면 공간이 좁다면 Select를 사용한다.

## HTML 구조

```html
<!-- 그룹 (접근성: fieldset + legend) -->
<fieldset class="ds-form-group">
  <legend class="ds-form-label">
    <span>그룹 제목 <span class="ds-form-label__required" aria-hidden="true">필수</span></span>
  </legend>
  <div class="ds-form-content [ds-form-content--error]">
    <div class="ds-check-group [ds-check-group--column]">

      <!-- 단일 체크박스 아이템 -->
      <div class="ds-check-item [ds-check-item--medium|ds-check-item--large]">
        <input type="checkbox" id="id" [checked] [disabled]>
        <label for="id">레이블</label>
        <!-- 부가 설명 (선택) -->
        <div class="ds-check-item__desc">
          <p class="ds-check-item__text">부가 설명 텍스트</p>
        </div>
      </div>

    </div>
  </div>
  <p class="[ds-form-hint|ds-form-hint ds-form-hint--error]">메시지</p>
</fieldset>
```

> 클래스명 목록은 위 **네이밍** 섹션을 참고한다.

## 코드 예시

### 상태

<Canvas of={CheckboxStories.상태} />

```html
<!-- 기본 -->
<div class="ds-check-item ds-check-item--medium">
  <input type="checkbox" id="chk-1">
  <label for="chk-1">기본</label>
</div>

<!-- 선택됨 -->
<div class="ds-check-item ds-check-item--medium">
  <input type="checkbox" id="chk-2" checked>
  <label for="chk-2">선택됨</label>
</div>

<!-- 중간 선택 (JS로 설정) -->
<div class="ds-check-item ds-check-item--medium">
  <input type="checkbox" id="chk-3">
  <label for="chk-3">중간 선택</label>
</div>
<script>document.getElementById('chk-3').indeterminate = true;</script>

<!-- 비활성화 -->
<div class="ds-check-item ds-check-item--medium">
  <input type="checkbox" id="chk-4" disabled>
  <label for="chk-4">비활성화</label>
</div>

<!-- 에러 -->
<div class="ds-form-content ds-form-content--error">
  <div class="ds-check-group ds-check-group--column">
    <div class="ds-check-item ds-check-item--medium">
      <input type="checkbox" id="chk-5">
      <label for="chk-5">에러 상태</label>
    </div>
  </div>
</div>
<p class="ds-form-hint ds-form-hint--error">하나 이상 선택해 주세요.</p>
```

> `indeterminate` 상태는 HTML 속성이 없으며 **반드시 JS**로 설정해야 합니다.  
> `input.indeterminate = true`

<Canvas of={CheckboxStories.전체동의} />

  </div>

## 접근성

- 체크박스 그룹은 `<fieldset>` + `<legend>`로 감싸 그룹의 목적을 스크린리더에 전달한다.
- 각 `<input>`의 `id`와 `<label>`의 `for`를 반드시 연결한다.
- `disabled` 상태는 스크린리더에 "비활성화"로 읽히므로 별도 안내 문구 불필요.
- 에러 메시지(`.ds-form-hint--error`)는 `aria-describedby`로 입력 요소와 연결하면 더욱 접근성이 높아진다.
- `indeterminate` 상태는 `aria-checked="mixed"` 속성을 함께 제공하는 것을 권장한다.
- 키보드: `Space`로 선택/해제, `Tab`으로 항목 간 이동.
