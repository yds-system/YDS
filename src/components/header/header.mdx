# 헤더 (Header)

## 개요

사이트 상단에 위치하는 헤더 컴포넌트입니다.
로고, 유틸리티 메뉴, 액션 버튼(검색·로그인·회원가입·전체 메뉴)으로 구성됩니다.
PC 화면에서는 GNB(메인 메뉴)가 헤더 하단에 붙어 표시됩니다.

---

## 네이밍

> KRDS 구성을 기준으로 ds- BEM 규칙에 따라 이름을 붙였습니다. KRDS 원본 클래스는 표의 'KRDS 원본' 열을 참고하세요.

## 사용 기준

- 모든 페이지에 공통으로 사용하는 컴포넌트입니다.
- PC(>=1280px)에서는 ds-main-menu(GNB)가 헤더 내부에 포함됩니다.
- 모바일에서는 전체 메뉴 버튼(ds-header__action-btn--all-menu)으로 슬라이드 메뉴를 엽니다.
