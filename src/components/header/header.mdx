# Header

헤더

## 개요

사이트 상단에 위치하는 헤더 컴포넌트입니다.
로고, 유틸리티 메뉴, 액션 버튼(검색·로그인·회원가입·전체 메뉴)으로 구성됩니다.
PC 화면에서는 GNB(메인 메뉴)가 헤더 하단에 붙어 표시됩니다.

---

## 네이밍

> KRDS 구성을 기준으로 yds- BEM 규칙에 따라 이름을 붙였습니다. KRDS 원본 클래스는 표의 'KRDS 원본' 열을 참고하세요.

## 언제 사용하는지

- 모든 페이지 상단에 공통으로 배치합니다.
- PC(≥1280px)에서는 `yds-main-menu`(GNB)가 헤더 하단에 붙어 표시됩니다.
- 모바일에서는 전체 메뉴 버튼(`yds-header__action-btn--all-menu`)을 클릭해 슬라이드 패널을 엽니다.

---

## 사용하지 말아야 할 때

- 전용 인쇄 뷰, 임베드 페이지 등 전역 탐색이 필요 없는 단독 화면에는 포함하지 않습니다.
