# Pagination

페이지네이션

## 개요

여러 페이지로 나뉜 콘텐츠를 탐색하는 컴포넌트입니다.  
기본 클래스: `yds-pagination`

## 언제 사용하는지

- 검색 결과, 게시판 목록 등 **페이지 단위로 나뉜 콘텐츠**를 탐색할 때
- 한 화면에 표시할 항목 수가 정해져 있고, **이전/다음/특정 페이지로 이동**해야 할 때

---

## 사용하지 말아야 할 때

- 항목 수가 적어 한 화면에 모두 표시 가능한 경우
- 무한 스크롤(Infinite Scroll)로 처리하는 콘텐츠에는 사용하지 않는다.

---

## 종류

| 구성 | 설명 |
|---|---|
| 처음·이전·번호·다음·마지막 | 전체 탐색 버튼 + 페이지 번호 |
| 이전·번호·다음 | `showFirstLast: false` — 처음·마지막 버튼 생략 |

---

## HTML 구조

```html
<nav aria-label="페이지 탐색">
  <div class="yds-pagination">

    <!-- 처음 버튼 (비활성: span, 활성: a) -->
    <a class="yds-pagination__move-btn yds-pagination__move-btn--first" href="#">처음</a>

    <!-- 이전 버튼 (아이콘만) -->
    <a class="yds-pagination__move-btn yds-pagination__move-btn--prev" href="#">
      <span class="sr-only">이전 페이지</span>
    </a>

    <!-- 페이지 번호 목록 -->
    <div class="yds-pagination__list">
      <a class="yds-pagination__link" href="#" data-page="1">1</a>
      <span class="yds-pagination__link yds-pagination__link--ellipsis" aria-hidden="true"></span>
      <a class="yds-pagination__link" href="#" data-page="3">3</a>
      <!-- 현재 페이지 -->
      <span class="yds-pagination__link yds-pagination__link--current" aria-current="page">
        <span class="sr-only">현재페이지 </span>4
      </span>
      <a class="yds-pagination__link" href="#" data-page="5">5</a>
      <span class="yds-pagination__link yds-pagination__link--ellipsis" aria-hidden="true"></span>
      <a class="yds-pagination__link" href="#" data-page="10">10</a>
    </div>

    <!-- 다음 버튼 (아이콘만) -->
    <a class="yds-pagination__move-btn yds-pagination__move-btn--next" href="#">
      <span class="sr-only">다음 페이지</span>
    </a>

    <!-- 마지막 버튼 -->
    <a class="yds-pagination__move-btn yds-pagination__move-btn--last" href="#">마지막</a>

  </div>
</nav>
```

### 비활성 버튼 (첫 페이지에서 이전·처음)

```html
<!-- 비활성: <a> 대신 <span> + aria-disabled -->
<span class="yds-pagination__move-btn yds-pagination__move-btn--first yds-pagination__move-btn--disabled" aria-disabled="true">처음</span>
<span class="yds-pagination__move-btn yds-pagination__move-btn--prev yds-pagination__move-btn--disabled" aria-disabled="true">
  <span class="sr-only">이전 페이지</span>
</span>
```

> `yds-pagination__move-btn--first` / `yds-pagination__move-btn--last`는 KRDS 기본 패턴에 없는 **디자인 시스템 확장 클래스**입니다.

## 반응형

| 화면 | 동작 |
|---|---|
| PC (`769px` 이상) | 처음 · 이전 · [번호] · 다음 · 마지막 한 줄 표시 |
| 모바일 (`768px` 이하) | 페이지 번호 그룹이 첫 행 전체 너비로 표시되고, 이전·다음 버튼이 두 번째 행 |

## 접근성

### nav와 aria-label

- 페이지네이션 전체를 `<nav aria-label="페이지 탐색">`으로 감싸 스크린리더에 탐색 랜드마크임을 알린다.
- 같은 페이지에 여러 `<nav>`가 있을 경우 `aria-label`로 구분한다.

### 현재 페이지

- 활성 페이지에 `aria-current="page"`를 부여한다.
- `<span class="sr-only">현재페이지 </span>`으로 스크린리더에 맥락을 추가 제공한다.

### 비활성 버튼

- 비활성 버튼은 `<a>` 대신 `<span>`으로 렌더링해 포커스와 클릭을 모두 차단한다.
- `aria-disabled="true"`를 함께 부여해 보조 기술에도 상태를 전달한다.

### 화살표 아이콘 버튼

- 이전·다음 버튼은 아이콘만 표시되므로 `<span class="sr-only">이전 페이지</span>`으로 레이블을 제공한다.

### 말줄임 구분자

- `yds-pagination__link--ellipsis` 요소는 장식용 `<span>`이므로 `aria-hidden="true"`를 적용한다.
