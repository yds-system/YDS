# Button

버튼

## 개요

사용자의 액션을 트리거하는 인터랙티브 요소입니다.  
기본 클래스: `yds-btn`

---

## 언제 사용하는지

- 폼 제출, 저장, 삭제 등 **명확한 사용자 액션**이 필요할 때
- 다음 단계로 이동하거나 특정 기능을 실행할 때
- 여러 선택지 중 하나의 행동을 강조해야 할 때

## 사용하지 말아야 할 때

- 페이지 이동이 목적이라면 **링크** 컴포넌트(`yds-link`)를 사용한다. 버튼 외형의 링크(Primary·Secondary 등)가 필요한 경우에만 `<a class="yds-btn yds-btn--primary">` 형식을 쓴다.
- 같은 화면에 **Primary 버튼을 2개 이상** 두지 않는다.
- 아이콘 전용 버튼(`.yds-btn--icon`)은 `<span class="sr-only">`로 텍스트를 반드시 제공해야 한다. 보조 텍스트 없이 사용하지 않는다.
- 비활성화(`disabled`) 상태를 기본값으로 두지 않는다. 활성화 조건이 충족되면 자동으로 활성화되어야 한다.

### 아이콘 포함

아이콘은 장식용이므로 `aria-hidden="true"`를 반드시 추가합니다.

<Canvas of={ButtonStories.아이콘포함} />

```html
<!-- 오른쪽 아이콘 -->
<button type="button" class="yds-btn yds-btn--primary yds-btn--small">
  검색 <i class="yds-icon yds-ico-sch" aria-hidden="true"></i>
</button>

<!-- 왼쪽 아이콘 -->
<button type="button" class="yds-btn yds-btn--primary yds-btn--small">
  <i class="yds-icon yds-ico-sch" aria-hidden="true"></i> 검색
</button>
```

### 아이콘 전용

<Canvas of={ButtonStories.아이콘전용} />

```html
<!-- sr-only로 텍스트를 반드시 제공 -->
<button type="button" class="yds-btn yds-btn--icon yds-btn--medium">
  <span class="sr-only">검색</span>
  <i class="yds-icon yds-ico-sch" aria-hidden="true"></i>
</button>

<!-- 테두리 원형 버튼 -->
<button type="button" class="yds-btn yds-btn--icon yds-btn--large yds-btn--border">
  <span class="sr-only">새로고침</span>
  <i class="yds-icon yds-ico-refresh" aria-hidden="true"></i>
</button>
```

### 비활성화

`<button>`과 `<a>` 태그의 비활성화 처리 방식이 다릅니다.

<Canvas of={ButtonStories.비활성화} />

```html
<!-- button: HTML disabled 속성 사용 (포커스 자동 제거) -->
<button type="button" class="yds-btn yds-btn--primary" disabled>Primary</button>
<button type="button" class="yds-btn yds-btn--secondary" disabled>Secondary</button>

<!-- a 태그 버튼 외형 링크: .yds-btn--disabled 클래스 + aria-disabled + tabindex -->
<a href="#" class="yds-btn yds-btn--secondary yds-btn--small yds-btn--disabled" aria-disabled="true" tabindex="-1">비활성 링크 버튼</a>
```

## 접근성

- `<button type="button">`을 기본으로 사용한다. 폼 제출이면 `type="submit"`.
- 아이콘 전용 버튼은 `<span class="sr-only">설명</span>`을 반드시 포함한다.
- 버튼 안의 장식용 아이콘(`<i class="yds-icon ...">`)에는 `aria-hidden="true"`를 추가해 스크린 리더가 읽지 않게 한다.
- **비활성화 처리:**
  - `<button>`: `disabled` HTML 속성 사용 → 포커스·이벤트 자동 차단
  - `<a>` 태그: `disabled` 속성이 없으므로 `.yds-btn--disabled` 클래스 + `aria-disabled="true"` + `tabindex="-1"` 을 모두 설정한다
  - 포커스를 유지해야 하는 `<button>`의 경우 `disabled` 대신 `aria-disabled="true"` + CSS로 처리한다
- focus 스타일은 KRDS 공통 CSS(`:focus`)에 의해 자동 적용된다.
