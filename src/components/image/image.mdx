# 이미지 (Image)

콘텐츠 영역에 삽입되는 이미지 컴포넌트입니다.  
비율(aspect-ratio)을 고정하고 `object-fit: cover`로 이미지를 채워 레이아웃이 흔들리지 않습니다.

---

## 개요

- **블록**: `ds-image`
- **KRDS 원본**: KRDS 이미지 기준 적용 (reference HTML 미제공, component.css 미포함)

## 언제 사용하는지

- 카드·게시글·배너 등 콘텐츠 영역에 이미지를 삽입할 때
- 비율을 고정해야 할 때 (썸네일, 갤러리 등)

## 사용하지 말아야 할 때

- 로고·아이콘처럼 잘리지 않게 전체를 보여줘야 하는 이미지는 `ds-logo` 또는 `ds-icon`을 사용한다.

## 접근성

- **`alt` 필수**: 의미 있는 이미지는 반드시 내용을 설명하는 대체 텍스트를 제공한다.
- **장식 이미지**: 순수 장식 목적이면 `alt=""`로 설정해 스크린 리더가 건너뛰도록 한다.
- 배경 이미지(`background-image`)로 처리하면 스크린 리더가 읽지 못하므로, 콘텐츠 이미지는 반드시 `<img>` 태그를 사용한다.
