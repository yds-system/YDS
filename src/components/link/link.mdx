# 링크 텍스트 (Link Text)

인라인 또는 독립형으로 사용하는 텍스트 링크 컴포넌트입니다.  
버튼과 동일한 `ds-btn` 기반이지만 고정 높이 없이 텍스트 흐름에 따라 자연스럽게 렌더링됩니다.

---

## 언제 사용하는지

- 문장 내 **인라인 링크** 또는 독립된 **이동 링크**가 필요할 때
- 클릭 시 **외부 페이지나 새 창**으로 이동함을 시각적으로 나타낼 때 (ds-ico-go 아이콘)
- 버튼처럼 생겼지만 **페이지 이동**이 목적인 경우 `<button>` 대신 `<a>`로 마크업해야 할 때

## 사용하지 말아야 할 때

- 폼 제출·저장 같은 **동작(action)** 이 목적이면 버튼을 사용한다.
- 이미 버튼 컴포넌트(`.ds-btn.ds-btn--primary` 등)로 충분히 표현되는 경우 중복 사용하지 않는다.

---

## HTML 구조

### 기본 (밑줄 항상)

```html
<a href="/path" class="ds-btn ds-btn--medium ds-btn--link">
  <span class="ds-btn__text">링크 텍스트</span>
</a>
```

### 새 창 + 아이콘

```html
<a href="https://example.com" class="ds-btn ds-btn--medium ds-btn--link"
   target="_blank" title="새 창 열림">
  <span class="ds-btn__text">외부 링크</span>
  <i class="ds-icon ds-ico-go" aria-hidden="true"></i>
</a>
```

### 본문 텍스트 색상 (basic)

```html
<a href="/path" class="ds-btn ds-btn--large ds-btn--link ds-btn--basic"
   target="_blank" title="새 창 열림">
  <span class="ds-btn__text">본문 텍스트 컬러 링크</span>
  <i class="ds-icon ds-ico-go" aria-hidden="true"></i>
</a>
```

### 상호작용 시 밑줄

```html
<a href="/path" class="ds-btn ds-btn--large ds-btn--link ds-btn--basic">
  <span class="ds-btn__text ds-btn__text--hidden">가상 클래스 상태 시 밑줄</span>
</a>
```

### 밑줄 없음

```html
<a href="/path" class="ds-btn ds-btn--large ds-btn--link ds-btn--basic">
  <span>밑줄 없음</span>
</a>
```

### 순수 (pure) — 상호작용 시 색상 유지

```html
<a href="/path" class="ds-btn ds-btn--medium ds-btn--link ds-btn--pure">
  <span class="ds-btn__text">가상 클래스 상태 시 컬러 유지</span>
</a>
```

---

## CSS 클래스

| 클래스 | 설명 |
|---|---|
| `ds-btn ds-btn--link` | 링크 텍스트 기본 (`<a>` 요소에 적용, `../button/button.css` 필요) |
| `ds-btn--xsmall` `ds-btn--small` `ds-btn--medium` `ds-btn--large` `ds-btn--xlarge` | 크기 (기본: `large`) |
| `ds-btn--basic` | 본문 텍스트 색상 (`--krds-light-color-text-basic`) |
| `ds-btn--pure` | 상호작용 시 색상 변경 없이 기본 색상 유지 |
| `ds-btn--basic ds-btn--pure` | 상호작용 시 본문 텍스트 색상 유지 |
| `.ds-btn__text` | 텍스트에 밑줄 항상 표시 (`<span>` 자식에 적용) |
| `.ds-btn__text.ds-btn__text--hidden` | 기본은 투명 밑줄, 상호작용 시 표시 |
| `ds-icon ds-ico-go` | 외부 링크 아이콘 (`<i>` 요소) |

---

## 색상 시스템

| 상태 | default | basic |
|---|---|---|
| 기본 | `--krds-light-color-link-default` | `--krds-light-color-text-basic` |
| hover | `--krds-light-color-link-hover` | 동일 (pure 아닐 때) |
| active / focus | `--krds-light-color-link-pressed` | 동일 (pure 아닐 때) |
| visited | `--krds-light-color-link-visited` | 동일 (pure 아닐 때) |
| disabled | `--krds-light-color-text-disabled` | 동일 |

`ds-btn--pure` 수정자를 추가하면 상호작용 상태에서도 기본 색상이 유지됩니다.

## 접근성

- 링크는 `<a href>` 요소로 마크업한다. 페이지 이동이 목적일 때 `<button>`을 사용하지 않는다.
- 새 창 열림 시 `target="_blank" title="새 창 열림"`을 추가해 사용자에게 동작을 미리 알린다.
- 외부 링크 아이콘(`.ds-icon.ds-ico-go`)은 `aria-hidden="true"`로 장식 처리하고, 링크 텍스트 자체로 목적지를 충분히 설명한다.
- 비활성 링크는 `pointer-events: none`으로 클릭을 막되, DOM에서 제거하지 않아 스크린리더가 텍스트를 읽을 수 있도록 유지한다.
- 키보드 포커스 시 `box-shadow` 기반 포커스 링이 표시된다 (button.css 상속).
