# Basic Layout

기본 레이아웃

## 개요

헤더·GNB·푸터로 구성된 사이트 전체 레이아웃 컴포넌트입니다.  
**PC 메가 메뉴**와 **모바일 슬라이드 메뉴**를 지원하며, 건너뛰기 링크와 키보드 탐색이 기본으로 제공됩니다.

---

## 네이밍

> KRDS 구성을 기준으로 yds- BEM 규칙에 따라 이름을 붙였습니다. KRDS 원본 클래스는 표의 'KRDS 원본' 열을 참고하세요.

## 언제 사용하는지

- 서비스의 모든 페이지에 공통 레이아웃(헤더 + GNB + 본문 + 푸터)을 제공할 때 사용합니다.
- `패턴/기본 레이아웃` 스토리에서 PC와 모바일 레이아웃을 한꺼번에 확인할 수 있습니다.

---

## 사용하지 말아야 할 때

- 전용 인쇄 뷰, 임베드, 팝업처럼 전역 탐색이 없는 단독 화면에는 사용하지 않습니다.
- 헤더·GNB·푸터를 각각 독립적으로 제어해야 한다면 개별 컴포넌트(`헤더`, `메인 메뉴`, `푸터`)를 직접 사용합니다.

## 접근성

- `#yds-skip-link a`는 평소에 화면 밖으로 숨겨져 있다가 Tab 포커스 시 화면 상단에 표시되어 본문으로 바로 이동할 수 있도록 한다.
- `<main id="main-content" tabindex="-1">`을 설정해 건너뛰기 링크 클릭 시 포커스가 본문으로 이동한다.
- PC GNB: `aria-expanded`, `aria-haspopup`, `aria-controls`로 열림/닫힘 상태와 연관 패널을 연결한다.
- PC GNB 키보드: `←` `→` 1depth 이동, `↓` 또는 `Enter` 서브메뉴 열기, `↑` `↓` 서브 트리거 이동, `Escape` 닫기.
- 현재 페이지 링크에 `aria-current="page"`와 `yds-main-menu__sub-link--current` 또는 `yds-main-menu-mobile__sub-trigger--current`를 함께 사용한다.
- 모바일 GNB: `role="dialog" aria-modal="true" aria-label="전체 메뉴"`로 다이얼로그 패턴을 적용한다.
- 모바일 GNB 열림 시 포커스를 닫기 버튼으로 이동하고, `Escape` 키로 닫으면 포커스가 트리거 버튼으로 돌아간다.
- `yds-header__action-btn--all-menu`에 `aria-expanded="true|false"`와 `aria-controls="mobile-nav"`를 설정한다.
- 로고 `<a>` 안에 `<span class="yds-sr-only">사이트명</span>`으로 스크린리더에 대체 텍스트를 제공한다.
