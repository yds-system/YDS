# Carousel

캐러셀 컨트롤

슬라이드(캐러셀)의 탐색·제어에 사용하는 버튼 및 인디케이터 UI 컴포넌트입니다.  
이 컴포넌트는 **컨트롤 UI만** 정의하며, Swiper.js 등 외부 슬라이더 라이브러리와 조합해 사용합니다.

---

## 개요

- **인디케이터 래퍼**: `ds-carousel__indicator`
- **KRDS 원본**: `swiper-indicator`

## 언제 사용하는지

- 이미지 슬라이드·배너·카드 캐러셀 등 **슬라이드 콘텐츠**가 있을 때
- 사용자가 슬라이드를 **이전/다음으로 탐색**하거나 **재생/멈춤을 제어**해야 할 때
- 현재 위치를 **불릿(점) 또는 숫자(분수)** 형태로 표시해야 할 때

## 사용하지 말아야 할 때

- 슬라이드가 1개뿐인 경우 컨트롤 버튼은 표시하지 않는다.
- 무한 루프 슬라이더에서 이전/다음 버튼을 비활성화하는 경우는 없다 (루프 해제 시에만 비활성 처리).

## Swiper 연동 예시 (JavaScript)

> Swiper는 기본적으로 자신의 클래스명(`swiper-button-disabled`, `swiper-pagination-bullet` 등)을 DOM에 추가합니다.  
> 클래스명을 `ds-carousel__*`로 바꾼 경우, **아래 옵션을 반드시 지정**해야 Swiper가 올바른 클래스를 사용합니다.

```js
const swiper = new Swiper('.swiper', {
  loop: true,
  autoplay: { delay: 2500, pauseOnMouseEnter: true },

  // ─── 이전/다음 버튼 ─────────────────────────────────────────────────────
  // disabledClass: Swiper가 첫/마지막 슬라이드에서 추가하는 비활성 클래스.
  // 기본값은 'swiper-button-disabled'이므로 반드시 덮어써야 한다.
  navigation: {
    prevEl: '.ds-carousel__move-btn--prev',
    nextEl: '.ds-carousel__move-btn--next',
    disabledClass: 'ds-carousel__move-btn--disabled',
  },

  // ─── 불릿 페이지네이션 ───────────────────────────────────────────────────
  // bulletClass / bulletActiveClass: Swiper가 생성하는 <span> 클래스.
  // 기본값은 'swiper-pagination-bullet' / 'swiper-pagination-bullet-active'이므로
  // 반드시 덮어써야 CSS가 적용된다.
  pagination: {
    el: '.ds-carousel__pagination',
    clickable: true,
    bulletClass: 'ds-carousel__bullet',
    bulletActiveClass: 'ds-carousel__bullet--current',
  },

  // ─── 분수형 페이지네이션 (type: 'fraction' 사용 시) ─────────────────────
  // currentClass / totalClass: Swiper가 생성하는 현재/전체 숫자 <span> 클래스.
  // 기본값은 'swiper-pagination-current' / 'swiper-pagination-total'.
  //
  // pagination: {
  //   el: '.ds-carousel__pagination',
  //   type: 'fraction',
  //   currentClass: 'ds-carousel__pagination-current',
  //   totalClass:   'ds-carousel__pagination-total',
  // },
});

// ─── 재생/멈춤 버튼 토글 ─────────────────────────────────────────────────────
const $play = document.querySelector('.ds-carousel__play-btn');
const $stop = document.querySelector('.ds-carousel__stop-btn');

$play.hidden = true; // 초기: 재생 중이므로 재생 버튼 숨김

$stop.addEventListener('click', () => {
  swiper.autoplay.stop();
  $stop.hidden = true;
  $play.hidden = false;
});
$play.addEventListener('click', () => {
  swiper.autoplay.start();
  $play.hidden = true;
  $stop.hidden = false;
});
```

## 접근성

- 모든 버튼은 아이콘만 표시되므로 `<span class="sr-only">`로 스크린리더용 텍스트를 반드시 제공한다.
- 비활성 버튼에는 `aria-disabled="true"`를 추가한다. `disabled` 속성은 탭 포커스를 막으므로, 스크린리더 사용자가 버튼 존재를 인식할 수 있도록 `aria-disabled`를 우선 사용한다.
- 재생/멈춤 버튼은 상태에 따라 하나만 DOM에 표시하거나 `hidden` 속성으로 전환한다.
- 더보기 버튼은 링크(`<a>`)로 마크업하며 `href`에 목록 페이지 URL을 지정한다.
- 인디케이터가 슬라이드 영역 밖에 위치할 경우 `aria-label="슬라이드 컨트롤"` 등으로 역할을 명시한다.
