# 배지 (Badge)

상태·카테고리·숫자 등 짧은 정보를 강조해 표시하는 레이블 요소입니다.  
텍스트 옆, 아이콘 위, 목록 항목 끝 등 다양한 위치에 인라인으로 사용합니다.

---

## 언제 사용하는지

- 항목의 **상태**를 한눈에 표시할 때 (진행 중, 완료, 오류 등)
- **숫자 알림** (읽지 않은 메시지, 미확인 건수)을 표시할 때
- 카테고리·태그 라벨을 색상으로 구분해 표시할 때

## 사용하지 말아야 할 때

- 클릭 가능한 필터·선택 항목에는 태그(Tag) 컴포넌트를 사용한다.
- 긴 텍스트나 여러 줄이 필요한 경우에는 별도 레이블/설명 영역을 사용한다.

---

## HTML 구조

```html
<!-- 기본 배지 -->
<span class="ds-badge bg-light-primary">진행 중</span>

<!-- 채우기 -->
<span class="ds-badge bg-success">완료</span>

<!-- 테두리 -->
<span class="ds-badge outline-danger">오류</span>

<!-- Large 크기 -->
<span class="ds-badge large bg-light-information">정보</span>

<!-- 숫자 배지 -->
<span class="ds-badge bg-danger number">5</span>
<span class="ds-badge bg-primary number">999+</span>

<!-- 점 배지 -->
<span class="ds-badge bg-danger dot" aria-label="알림 있음"></span>

<!-- 묶음 표시 -->
<div class="ds-badge-wrap">
  <span class="ds-badge bg-light-primary">기본</span>
  <span class="ds-badge bg-light-success">완료</span>
  <span class="ds-badge bg-light-danger">오류</span>
</div>
```

## CSS 클래스

### 스타일 (color 조합)

| 클래스 패턴 | 설명 |
|---|---|
| `outline-{color}` | 테두리만 표시, 배경 없음 |
| `bg-{color}` | 배경 채우기 (진한 색) |
| `bg-light-{color}` | 밝은 배경 채우기 (권장) |

### 색상

| `{color}` 값 | 의미 |
|---|---|
| `primary` | 기본·진행 중 |
| `secondary` | 보조 |
| `gray` | 일반·중립 |
| `point` | 포인트·강조 |
| `danger` | 오류·위험 |
| `warning` | 주의·경고 |
| `success` | 완료·성공 |
| `information` | 정보·안내 |
| `disabled` | 비활성 |

### 크기

| 클래스 | 설명 |
|---|---|
| (없음) | 기본 크기 |
| `large` | 큰 크기 |

### 유형

| 클래스 | 설명 |
|---|---|
| (없음) | 텍스트 레이블 |
| `number` | 숫자 배지 (pill 모양, 최소 너비 보장) |
| `dot` | 점 배지 (텍스트 없음, `aria-label` 필수) |

### 래퍼

| 클래스 | 설명 |
|---|---|
| `ds-badge-wrap` | 배지를 가로로 나열하는 flex 컨테이너 |

## 접근성

- 배지는 **보조 정보**이므로 단독으로 의미를 전달해야 할 때는 주변 문맥과 함께 사용한다.
- 점 배지(`.dot`)는 텍스트가 없으므로 `aria-label`로 의미를 반드시 제공한다.
- 숫자 배지가 알림 수를 나타낼 때는 `aria-label="읽지 않은 메시지 5개"` 형식으로 작성한다.
- 색상만으로 상태를 구분하지 않는다 — 텍스트 또는 아이콘을 함께 제공한다.
