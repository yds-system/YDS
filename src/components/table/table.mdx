# Table

표

구조화된 데이터를 행과 열로 표현하는 컴포넌트입니다.

---

## 개요

- **블록**: `yds-table`
- **래퍼**: `yds-table-wrap`
- **KRDS 원본**: `tbl` / `krds-table-wrap`

## 언제 사용하는지

- **목록형**: 동일한 속성을 가진 항목들을 나열할 때 (공지사항, 검색 결과 등)
- **가로 헤더형**: 하나의 항목에 대한 상세 정보를 키-값 형식으로 보여줄 때
- **체크박스 선택형**: 사용자가 항목을 선택해 일괄 처리해야 할 때

## 사용하지 말아야 할 때

- 단순 목록(제목+링크)은 `<ul>`, `<ol>` 목록 컴포넌트를 사용한다.
- 비교 대상이 없는 단독 데이터는 Definition List(`<dl>`)가 적합하다.
- 레이아웃 배치 목적으로 `<table>`을 사용하지 않는다.

## 접근성

### caption

- 모든 `<table>`에는 `<caption class="yds-table__caption">`을 작성해 표의 목적을 스크린리더에 전달한다.
- caption은 기본적으로 시각적으로 숨겨지지만(KRDS common.css), `yds-table__caption--visible` modifier로 표시할 수 있다.
- 내용: `"[표 이름]으로 [열1], [열2], ...로 구성되어 있습니다."` 형식을 권장한다.

### scope 속성

| 요소 | scope | 적용 상황 |
|---|---|---|
| `<thead> <th>` | `scope="col"` | 열 전체에 적용되는 헤더 |
| `<tbody> <th>` | `scope="row"` | 행 전체에 적용되는 헤더 |

### 체크박스 접근성

- 체크박스 `<label>`에 빈 텍스트 대신 `<span class="yds-sr-only">[행 제목] 선택</span>`으로 맥락을 제공한다.
- 전체 선택 체크박스에도 `<span class="yds-sr-only">전체 선택</span>`을 제공한다.
- `indeterminate` 상태는 `aria-checked="mixed"` 속성을 함께 제공하는 것을 권장한다.

### 반응형 카드형

- 카드형 전환 시에도 `<thead>`는 DOM에 유지되며 `display: none`으로만 숨긴다 (스크린리더 접근 유지).
- `data-label`의 내용이 열 헤더 텍스트와 일치해야 한다.
