export const UNCONFIRMED = (
  <span style={{ color: '#c97a00', fontWeight: 600, fontSize: '0.8em', marginLeft: '0.4em' }}>
    확인 필요
  </span>
);

export const ElementTable = ({ elements }) => (
  <table>
    <thead>
      <tr><th>요소</th><th>클래스명</th><th>설명</th></tr>
    </thead>

      {elements.map((el, i) => (

          <td>{el.description}</td>
        </tr>
      ))}
    </tbody>
  </table>
);

    <tbody>
      {modifiers.map((mod, i) => (
        <tr key={i}>
          <td>{mod.category}</td>
          <td><code>{mod.class}</code>{!mod.confirmed && UNCONFIRMED}</td>
          <td>{mod.description}</td>

  </table>

# 텍스트 영역 (Textarea)

## 개요

여러 줄 텍스트를 입력하는 폼 요소입니다.
글자 수 표시(`ds-count`)와 함께 사용하며, `ds-form-group` 구조를 텍스트 입력과 공유합니다.

---

## 네이밍

> KRDS 구성을 기준으로 ds- BEM 규칙에 따라 이름을 붙였습니다. KRDS 원본 클래스는 표의 'KRDS 원본' 열을 참고하세요.

## 언제 사용하는지

- 문의 내용, 메모, 비고 등 **여러 줄 텍스트** 입력이 필요할 때
- 글자 수 제한이 있어 **현재/최대 글자 수**를 표시해야 할 때

## 사용하지 말아야 할 때

- 한 줄 텍스트(이름, 이메일 등)에는 텍스트 입력(`ds-input`)을 사용한다.
